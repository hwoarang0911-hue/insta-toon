# 외형 (고정 스펙 — 변경 금지)

## 얼굴 비율
- 얼굴선은 둥글고 부드럽게, 턱은 뾰족하지 않다
- 이목구비는 얼굴 아래쪽 절반에 모인다
- 머리 크기는 전신 기준 약 1/6

## 머리 형태
- 어깨에 닿는 길이, 약간 웨이브, 검은색
- 가르마는 자연스럽게, 앞머리는 이마를 완전히 덮지 않는다

## 눈과 입
- 눈: 작은 점 형태. 흰자·홍채·하이라이트를 그리지 않는다
- 눈썹: 가늘고 짧게, 표정 변화의 대부분을 담당
- 코: 아주 작은 점 또는 짧은 선
- 입: 작은 선 하나

## 신체 비율
- 평범하고 아담한 체형, 약 6~6.5등신
- 어깨는 좁게, 손발은 단순화하되 형태는 알아볼 수 있게

## 의상 기본 구조
- 무지 긴팔 상의(맨투맨/니트) + 통 넓은 바지 + 단화
- 소지품: 각진 토트백, 헤드폰 또는 줄 이어폰, 가끔 커피컵·책·카메라
- **모든 의상·소지품은 무지.** 로고·워드마크·패턴 없음

## 펜선
- 손으로 그린 만년필 스케치, 두껍고 불규칙한 선
- 세부 규칙은 `brand/03_DRAWING_STYLE.md`

## 색상
- 흑백 기본, 배경색 흰색(#ffffff)
- 색을 쓸 경우 연한 파스텔 1~2색만 포인트

## 표정 범위 (이 4종 안에서만)

| 표정 | 묘사 |
|---|---|
| 생각 중 | 시선을 살짝 위로, 입은 다문 무표정 |
| 미소 | 눈은 그대로, 입꼬리만 살짝 올라감 |
| 좋아하는 순간 | 눈을 감고 옅은 미소 |
| 고민 중 | 턱에 손, 시선은 옆으로 |

- 놀람도 눈이 조금 커지는 정도까지만
- **얼굴이 안 보이는 컷도 정상이다.** 뒷모습·손·발 디테일 컷에서는 표정을 그리지 않는다

## 시점별 모습
| 시점 | 유지할 것 |
|---|---|
| 정면 | 눈 사이 간격, 머리 실루엣 |
| 옆모습 | 코는 아주 작게, 뒤통수 볼륨 유지 |
| 뒷모습 | 어깨 폭과 머리 길이로 식별 가능해야 함 |
| 위에서 | 정수리 가르마와 어깨선 |
| 아래에서 | 턱선을 각지게 만들지 않는다 |

## 금지되는 스타일 변화
- 헤어스타일·옷 스타일 변경
- 과장된 표정, 만화적 기호(땀방울·별눈·하트눈)
- 큰 눈, 광택 하이라이트 (일본 애니풍)
- 화려한 액세서리
- 의상·소지품에 실존 브랜드 로고·워드마크 노출
- 등신 비율 변경 (SD·과장 비율 금지)

# 성격 (연기 지침 — 스토리 규칙 아님)

- 관찰을 좋아한다. 말하기 전에 오래 듣는다
- 좋아하는 것 앞에서는 조용히 오래 머문다
- 놀라도 크게 표현하지 않는다
- 결론을 서두르지 않는다. **아무 결론 없이 끝나도 되는 사람이다**

## 배경 서사

### 직업 — 비공개 (의도된 여백)
- 무슨 일을 하는지 밝히지 않는다. 사무실 내부·업무 내용·직함은 그리지 않는다
- 바쁜 일상은 이른 출근길, 늦은 귀갓길 같은 장면으로만 암시한다

### 피아노 — 장기 서사 (아껴 쓸 것)
- 어린 시절 배우다 그만뒀다. 지금은 치지 않는다
- 연재에서는 가끔 스치듯만 보여준다
- **"다시 건반 앞에 앉는 날"은 작가 승인 없이 그리지 않는다**
