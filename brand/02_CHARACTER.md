# 주인공 — 쉼이

기준 이미지: `assets/character_sheet.png` (모든 컷은 이 시트를 따른다)
프로필 이미지: `assets/profile.png`

## 기본 정보
- 이름: **쉼이** (Restnote의 rest = 쉼표에서. 해시태그: #쉼이)
- 나이: 20대 중반 여성
- 소개: 조용히 생각하는 시간을 좋아한다. 음악, 책, 여행을 좋아하고 일상에서 작은 영감을 발견한다. 사색적이지만 긍정적이고 따뜻한 마음을 가졌다.
- 무드: 조용하고 따뜻한 일상 속에서, 작은 행복을 찾는 사람.

## 외형 (고정 스펙)
- 어깨에 닿는 자연스러운 머리, 약간 웨이브, 검은색
- 작은 점 형태의 눈, 담백한 표정
- 작은 코와 입, 얼굴선은 둥글고 부드럽게
- 평범하고 아담한 체형
- 옷: 무지 긴팔 상의(맨투맨/니트) + 통 넓은 바지 + 단화
- 소지품: 늘 함께하는 각진 토트백, 헤드폰 또는 줄 이어폰, 가끔 커피컵·책·카메라

## 표정 4종 (이 안에서만 사용)
| 표정 | 묘사 |
|---|---|
| 생각 중 | 시선을 살짝 위로, 입은 다문 무표정 |
| 미소 | 눈은 그대로, 입꼬리만 살짝 올라감 |
| 좋아하는 순간 | 눈을 감고 옅은 미소 |
| 고민 중 | 턱에 손, 시선은 옆으로 |

## 성격
- 관찰을 좋아한다. 말하기 전에 오래 듣는다.
- 좋아하는 것 앞에서는 조용히 오래 머문다.
- 놀라도 크게 표현하지 않는다. 눈만 조금 커진다.

## 좋아하는 것들
책 · 음악(클래식) · 커피 · 여행과 사진 · 산책 · 벤치에 앉아 있기

## 금지
- 과장된 표정, 만화적 이모티콘 표현(땀방울, 별눈 등)
- 헤어스타일·옷 스타일 변경
- 화려한 액세서리
- 허락 없는 새 캐릭터 추가 (군중은 얼굴 없는 실루엣으로만)
