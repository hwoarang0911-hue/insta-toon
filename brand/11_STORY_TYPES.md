# 이야기 유형과 자연스러움 — 기준 문서

> **이 문서가 「이야기가 어떻게 생겼는가」의 유일한 기준이다.**
> 사건·감정 레벨·대사·구도·흐름·결말은 전부 여기서 정한다.
> 캐릭터 외형은 `brand/02_CHARACTER.md`, 그림체는 `brand/03_DRAWING_STYLE.md`가 기준이며
> 이 문서는 그 둘을 다루지 않는다.

## 이 문서가 만들어진 이유

Restnote는 한동안 **메시지를 설명하는 감성툰**으로 흘렀다.
추상적인 주제를 먼저 정하고 장면을 끼워 맞췄고, 루아가 작가의 메시지를 대신 말했고,
모든 컷의 대사가 완결된 감성 문장이었고, 마지막 컷이 늘 교훈을 설명했다.

방향을 바꾼다.

> **교훈을 전달하는 감성툰이 아니라, 실제로 있었을 법한 작은 순간을 관찰하고 기록하는 인스타툰.**

# 1. 스토리 유형 10종

에피소드마다 **주 유형 1개**를 고르고, 필요하면 **보조 유형 1개**까지만 섞는다.
세 개 이상 섞으면 유형이 없는 것과 같다.

| 코드 | 이름 | 무엇을 하는 이야기인가 | 마지막 컷은 | 대사량 |
|---|---|---|---|---|
| **OBSERVE** | 관찰형 | 눈앞의 것을 오래 본다. 해석하지 않는다 | 대상이나 풍경 그대로 | 매우 적음 |
| **RELATE** | 공감형 | 누구나 해본 사소한 행동을 그대로 보여준다 | 그 행동의 마지막 동작 | 적음 |
| **STORY** | 에피소드형 | 작은 사건이 일어나고 끝난다 | 사건이 끝난 자리 | 보통 |
| **TASTE** | 취향형 | 좋아하는 것을 고르고 가지는 과정 | 고른 것을 쥔 손 | 적음 |
| **REFLECTION** | 사색형 | 생각이 한 번 움직인다 | 생각이 멎은 채의 행동 | 적음 |
| **CINEMA** | 시네마형 | 장면의 전환과 빛으로만 끌고 간다 | 컷의 여백 | 거의 없음 |
| **CULTURE** | 문화 감상형 | 음악·전시·책 앞에서의 시간 | 감상이 끝난 뒤의 동작 | 적음 |
| **DIARY** | 기록형 | 하루의 조각을 나열한다 | 나열의 마지막 조각 | 짧게 여러 번 |
| **DEADPAN** | 담담 유머형 | 사소한 어긋남을 표정 없이 본다 | 어긋남의 결과 | 짧고 건조 |
| **SILENCE** | 무대사 실험형 | 대사 0개로 끌고 간다 | 마지막 행동 | **0** |

## 기본 선택 우선순위

사용자가 유형을 지정하지 않으면 **이 순서로** 검토한다.

```
OBSERVE → RELATE → STORY → TASTE → REFLECTION
```

- **감성적·철학적 소재라고 해서 자동으로 REFLECTION을 고르지 않는다.** 이것이 지금까지의 가장 큰 실수였다
- 소재가 클래식·계절·사색처럼 보여도 먼저 OBSERVE로 짤 수 있는지 시도한다
- REFLECTION은 **앞의 네 유형으로 도저히 안 될 때** 쓴다
- CINEMA·SILENCE·DEADPAN·DIARY·CULTURE는 로테이션에 변화를 줄 때 의도적으로 선택한다
- **직전 두 화와 같은 주 유형을 쓰지 않는다**

# 2. 감정 레벨 0~5

| 레벨 | 상태 | 사용 |
|---|---|---|
| **0** | 아무 감정 없음. 그냥 봄 | 권장 |
| **1** | 아주 옅게 좋거나 아쉬움. 표정에 거의 안 드러남 | **기본값** |
| **2** | 알아챌 정도의 감정. 입꼬리나 눈이 조금 움직임 | 권장 |
| 3 | 분명한 감정. 행동이 바뀔 정도 | 특별한 화만 |
| 4 | 큰 감정 | **사용 금지** |
| 5 | 격한 감정 | **사용 금지** |

- **기본 작업 범위는 0~2다.** 3은 연재에서 아주 드물게만
- **4 이상이 나오면 그 스크립트는 다시 쓴다** (`pipeline/NATURALNESS_CHECKLIST.md`)
- 작은 사건에 큰 감정을 붙이지 않는다. 사건의 크기와 감정의 크기를 맞춘다

# 3. MOOD 레이어

에피소드마다 아래를 먼저 고정한다. **정하기 전에 컷을 쓰지 않는다.**
이 값들이 배경 묘사·구도·대사 밀도를 자동으로 결정한다.

| 항목 | 무엇을 정하나 | 예 |
|---|---|---|
| `season` | 계절 | 한여름 / 늦가을 |
| `time` | 시각 | 오후 3시 / 퇴근 직후 / 새벽 |
| `weather` | 날씨 | 맑음 / 소나기 / 흐림 |
| `temperature` | 체감 온도 | 덥고 습함 / 서늘함 |
| `dominant_sound` | 그 공간을 채우는 소리 | 에어컨 실외기 / 빗소리 / 사람 말소리 |
| `visual_density` | 화면 정보량 | 비움 / 보통 / 빽빽함 |
| `pace` | 컷이 넘어가는 속도 | 느림 / 보통 |
| `texture` | 화면의 질감 | 마른 / 젖은 / 먼지 낀 |
| `light` | 빛의 성질 | 정오의 흰빛 / 창으로 든 사광 / 실내 형광 |

- MOOD는 **분위기 형용사가 아니라 촬영 조건**이다. "쓸쓸한"은 MOOD가 아니고 "흐림, 실내 형광, 마른"이 MOOD다
- `dominant_sound`는 무대사 컷을 설계할 때의 재료가 된다

# 4. 중심 사건 1개 원칙

**한 에피소드에 실제로 일어나는 일은 하나다.**

- 중심 사건은 **한 문장으로 쓸 수 있어야 하고, 눈에 보여야 한다**
  - ○ "카페에서 옆자리 사람이 두고 간 책을 집어 카운터에 맡겼다"
  - ✗ "취향의 소중함을 깨달았다" — 보이지 않는다. 사건이 아니라 주제다
- 사건이 두 개면 에피소드를 나눈다
- **사건 없이 사색만 이어지는 에피소드를 만들지 않는다**

## 추상 주제 → 구체적 순간 변환 (필수 단계)

사용자가 던진 주제가 추상적이면 **반드시 아래 순서로 내려온다.**

```
추상 주제
  → 실제 장소
  → 특정 시간
  → 캐릭터의 행동
  → 작은 변화나 사건
```

| ✗ 추상 주제 그대로 | ○ 구체적 순간으로 변환 |
|---|---|
| AI 시대에는 개인의 취향이 중요하다 | 무엇이든 만들어주는 입력창 앞에서 정작 만들고 싶은 것을 떠올리지 못한 밤 |
| 비발디의 여름에는 불안함이 있다 | 맑고 더운 카페에서 우연히 비발디의 여름 3악장을 들은 순간 |
| 물은 볼 때마다 다르다 | 퇴근길에 그냥 내린 역에서 강을 이십 분 서서 본 저녁 |

변환 결과에 **장소·시간·행동이 다 들어있지 않으면 아직 변환이 안 된 것이다.**

# 5. 생활 디테일 라이브러리

**모든 에피소드에 주제와 직접 관련 없는 현실적 디테일을 최소 하나 넣는다.**
이것이 "실제로 있었던 일"처럼 보이게 만드는 거의 유일한 장치다.

## 라이브러리

| 분류 | 디테일 |
|---|---|
| 사물의 움직임 | 에어컨 바람에 움직이는 영수증 · 컵 아래로 흐르는 물방울 · 테이블에 남은 물자국 |
| 몸에 붙은 것 | 어깨에서 내려오는 가방끈 · 손가락에 붙은 빨대 비닐 · 풀리는 신발 끈 |
| 무의식적 행동 | 테이블 아래에서 흔들리는 발 · 휴대전화 화면을 잠그는 행동 · 이어폰 한쪽만 빼는 행동 · 가방 안을 반복해서 찾는 행동 |
| 소리·기계 | 자동 재생으로 넘어간 음악 · 횡단보도 신호음 · 진동으로 울린 알림 |

## 규칙

- **생활 디테일을 주제의 상징처럼 쓰지 않는다.** 감정이 흔들린다고 커튼·낙엽·바람·파도를 넣지 않는다
- 디테일은 **주제와 무관해야** 제 역할을 한다. 주제를 거들면 그건 상징이지 디테일이 아니다
- 라이브러리 밖의 것을 새로 만들어도 되지만, 기준은 같다 — 사소하고, 실제로 있고, 의미가 없을 것

# 6. 대사량 가이드

| 유형 | 5컷 기준 대사 있는 컷 | 총 문장 수 |
|---|---|---|
| SILENCE | 0컷 | 0 |
| CINEMA | 0~1컷 | 0~2 |
| OBSERVE · TASTE | 1~2컷 | 2~4 |
| RELATE · DEADPAN · CULTURE · REFLECTION | 2~3컷 | 3~6 |
| STORY · DIARY | 3컷 | 4~7 |

## 기본 원칙

- **첫 번째 초안보다 반드시 줄인다.** 초안을 그대로 쓰지 않는다
- 실제 그 순간에 중얼거릴 법한 말을 쓴다
- **모든 문장을 완결된 감성 문장으로 만들지 않는다**
- 그림으로 보이는 것을 대사로 반복하지 않는다
- 대사가 없어도 되는 컷은 무대사로 둔다
- **5컷 기준 최소 한 컷은 무대사** (SILENCE·CINEMA는 더 많이)
- 캐릭터가 자기 감정을 완전히 이해하거나 설명하지 않아도 된다

## 권장 대사 (이 온도가 기준이다)

```
생각보다 시끄럽네.
왜 지금 생각났지.
그냥 넘길까 했는데.
한 번만 더.
아, 이건 좀 좋다.
분명 더웠는데.
이게 여름이었나.
그냥 여기 있을까.
```

## 경고 표현 — 나오면 자동 재검토

```
결국   어쩌면   문득   그제야   우리 모두
인생   진정한   소중한   깨달았다   본질   나다운   행복이란
```

무조건 금지는 아니지만 **감성 에세이형 문장을 만들 확률이 매우 높다.**
발견하면 삭제하거나 생활 언어로 바꾼다. 남기려면 그럴 이유가 있어야 한다.

> 말투·어미의 세부 규칙은 `brand/01_AUTHOR_PERSONA.md`가 기준이다. 여기서는 **양과 온도**만 정한다.

# 7. 마지막 컷 규칙

## 금지

- 교훈
- 메시지 요약
- 감정의 정답
- 독자에게 던지는 철학적 질문
- 의미 있어 보이기 위한 시적 문장
- 갑작스러운 미소
- 감동을 강조하는 빛이나 바람
- 현실에 없던 상징물

## 허용

- 작은 행동
- 반복 (앞 컷의 행동을 한 번 더)
- 풍경
- 침묵
- 시선
- 현실로 돌아오는 행동
- 사물의 상태 변화
- 짧고 미완성된 독백

## 삭제 테스트 (필수)

마지막 컷을 쓴 뒤 반드시 확인한다.

> **마지막 독백을 삭제해도 에피소드가 유지되는가?**

- **유지된다** → 독백을 **삭제한다**
- **유지되지 않는다** → 독백을 복구하지 말고 **행동·사물·구도를 개선한다**

독백이 있어야만 성립하는 에피소드는 이야기가 아니라 캡션이다.

# 8. 구도 변화 규칙

## 5컷 기준 최소 조건

- [ ] 와이드숏 1컷 이상
- [ ] 사물 또는 손 디테일숏 1컷 이상
- [ ] 캐릭터 얼굴 전체가 보이지 않는 컷 1컷 이상
- [ ] 무대사 컷 1컷 이상
- [ ] **동일한 카메라 거리 3회 이상 연속 사용 금지**
- [ ] 컷마다 화면의 역할이 달라야 함

## 사용 가능한 구도

```
공간 와이드숏 · 캐릭터 중경 · 사물 클로즈업 · 캐릭터 시점 · 어깨너머 구도
뒷모습 · 손이나 발 디테일 · 빈 풍경 · 얼굴 일부 · 위에서 내려다보는 구도
바닥 가까이에서 보는 구도
```

**컷마다 배경만 바꾸지 말고 카메라의 위치와 정보량을 바꾼다.**
같은 자리에서 배경만 갈아끼우면 다섯 컷이 한 컷처럼 읽힌다.

> 샷의 용도별 기본값과 시선 흐름은 `brand/08_VISUAL_LANGUAGE.md`를 본다.

# 10. 에피소드 생성 템플릿

```yaml
episode:
  id:                    # ep004
  title:
  primary_type:          # OBSERVE / RELATE / STORY / TASTE / REFLECTION / CINEMA / CULTURE / DIARY / DEADPAN / SILENCE
  secondary_type:        # 없으면 비움
  emotion_level:         # 0~2 기본

moment:
  concrete_event:        # 한 문장. 눈에 보이는 사건
  central_action:        # 루아가 실제로 한 행동
  life_detail:           # 주제와 무관한 생활 디테일 1개 이상

mood:
  season:
  time:
  weather:
  temperature:
  dominant_sound:
  visual_density:        # 비움 / 보통 / 빽빽함
  pace:                  # 느림 / 보통
  texture:
  light:
```

각 컷은 아래 항목을 채운다. **`visible_action`을 먼저 쓰고, `dialogue`는 마지막에 쓴다.**

```yaml
panel:
  visible_action:            # 화면에서 실제로 일어나는 일 (먼저 작성)
  character_reaction:        # 표정·몸의 반응 (표정 4종 안에서)
  dialogue:                  # 없으면 비움. 비우는 것이 기본
  composition:               # 8장의 구도 목록에서
  camera_distance:           # 와이드 / 중경 / 클로즈업 / 디테일
  background_detail:         # 필수 배경만
  continuity_from_previous:  # 앞 컷에서 무엇이 이어지는가
```

# 11. 유형별 컷 흐름 참고

기승전결은 **STORY와 REFLECTION에만 해당한다.** 나머지 유형에 강제하지 않는다.

| 유형 | 컷 흐름 |
|---|---|
| OBSERVE | 마주침 → 봄 → 더 봄 → 다른 게 보임 → 그대로 둠 |
| RELATE | 상황 → 사소한 행동 → 반복 → 어긋남 → 마무리 동작 |
| STORY | 발단 → 사건 → 반응 → 처리 → 끝난 자리 |
| TASTE | 여러 개 → 하나에 멈춤 → 만져봄 → 고름 → 쥔 손 |
| REFLECTION | 걸림 → 물음 → 목격 → 생각이 움직임 → 행동 |
| CINEMA | 빛 → 이동 → 정지 → 전환 → 여백 |
| CULTURE | 마주함 → 몰입 → 딴생각 → 돌아옴 → 끝난 뒤 |
| DIARY | 조각 → 조각 → 조각 → 조각 → 조각 (연결 느슨해도 됨) |
| DEADPAN | 기대 → 어긋남 → 무표정 → 재시도 → 같은 결과 |
| SILENCE | 전부 행동으로. 대사 0 |
