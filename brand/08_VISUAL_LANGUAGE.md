# Visual Language — 컷 문법

## 기본 원칙
- 3초 안에 상황 이해
- 한 컷 = 하나의 감정
- 한 컷 = 하나의 행동
- 배경보다 인물
- 여백을 두려워하지 않는다

## 카메라
| 용도 | 샷 |
|---|---|
| 기본 | 허리 위 미디엄 샷 |
| 감정 | 얼굴 클로즈업 |
| 상황 설명 | 전신 또는 풀 샷 (벤치, 산책로 등) |
| 여운 | 멀리서 본 작은 루아 + 넓은 여백, 또는 뒷모습 |

- 극단적 원근법, 로우앵글·하이앵글 금지
- 시점은 조용한 관찰자의 눈높이

## 표정
- 절제된 감정. 눈과 입만으로 표현
- 표정 4종(생각 중/미소/좋아하는 순간/고민 중) 안에서 해결
- 놀람도 눈이 조금 커지는 정도까지만

## 말풍선·텍스트
- 대사는 한 호흡에 읽히는 길이. **글자 수를 세지 말고 말이 자연스러운지를 본다**
- 내레이션은 컷 상단 여백에. 필요하면 2~3줄까지 쓴다
- 설명보다 대화, 대화보다 침묵
- 그림이 텍스트에 묻히지 않게만 한다 (글자 수 제한이 아니라 화면 비중의 문제)

## 시선 흐름
- 왼쪽 위 → 오른쪽 아래
- 표지는 중앙 집중 구도

## 비교·대조 컷 (트랙 A에서 자주 사용)
- 화면을 세로 점선으로 이등분해 좌/우 대비 (샘플: 브루크너/말러 2컷)
- 각 반쪽에 키워드 1줄 + 상징 그림 1개

## 색감
- 항상 일정. 에피소드 내 색 규칙 유지
- 채도 과하지 않게

## 마지막 컷 (여운 장)
- 결론을 강요하지 않는다
- 텍스트 0~1문장
- 루아가 작게 배치되고 여백이 화면의 60% 이상
- 소품(떨어지는 잎, 음표, 커피 김)으로 잔잔한 움직임 암시
