# Visual Language — 컷 문법

> 구도 **변화 규칙**(5컷 최소 조건)은 `brand/11_STORY_TYPES.md` 8장이 기준이다.
> 이 문서는 각 구도가 **무엇을 하는 도구인지**를 정의한다.

## 기본 원칙
- 3초 안에 상황 이해
- 한 컷 = 하나의 감정, 한 컷 = 하나의 행동
- 배경보다 인물, 단 **인물이 없는 컷도 있어야 한다**
- 여백을 두려워하지 않는다
- 작은 화면(모바일)에서도 잘 보이는 크기로 그린다
- 배경 묘사는 짧게, 텍스트는 크게
- 모든 컷 가장자리에 테두리선(외곽선)
- 비율은 4:5 (1080×1350)

## 구도 라이브러리

**컷마다 배경만 바꾸지 말고 카메라의 위치와 정보량을 바꾼다.**

| 구도 | 카메라 거리 | 무엇을 하는 컷인가 |
|---|---|---|
| 공간 와이드숏 | 와이드 | 장소와 시간을 한 번에 알려준다. 인물은 작아도 된다 |
| 캐릭터 중경 | 중경 | 행동을 보여준다. **기본값이지만 연속 3컷 금지** |
| 사물 클로즈업 | 디테일 | 생활 디테일이 사는 자리. 인물 없이 성립한다 |
| 손·발 디테일 | 디테일 | 행동의 질감. 표정 없이 감정을 전한다 |
| 캐릭터 시점 | 중경~와이드 | 루아가 보는 것을 독자도 본다. 얼굴이 안 나온다 |
| 어깨너머 | 중경 | 대상과 루아를 한 화면에 넣는다 |
| 뒷모습 | 중경~와이드 | 표정을 숨긴다. 여운 장의 기본 |
| 빈 풍경 | 와이드 | 인물이 없는 컷. 시간의 경과를 만든다 |
| 얼굴 일부 | 클로즈업 | 눈이나 입만. 감정 레벨을 올리지 않고 반응만 |
| 위에서 내려다보기 | 자유 | 테이블 위, 손에 든 것 |
| 바닥 가까이 | 자유 | 발, 신발, 젖은 바닥 |

- 극단적 원근법 금지
- 로우앵글·하이앵글은 **사물을 볼 때만** 허용 (인물을 올려/내려다보지 않는다)
- 시점은 조용한 관찰자의 눈높이가 기본

## 표정
- 절제된 감정. 눈과 입만으로 표현
- 표정 4종 안에서 해결 (`brand/02_CHARACTER.md`)
- **얼굴이 안 보이는 컷이 5컷 중 최소 하나 있어야 한다**

## 말풍선·텍스트

**콘티의 대사는 이미지 안에 손글씨로 그려진다** (캡션은 이미지 밖 게시글 본문).

- 대사는 한 호흡에 읽히는 길이. **글자 수를 세지 말고 말이 자연스러운지를 본다**
- 내레이션은 컷 상단 여백에
- 설명보다 대화, 대화보다 침묵
- **무대사 컷이 최소 하나 있어야 한다**
- 그림이 텍스트에 묻히지 않게 한다
- **글씨는 크게** — 작은 화면에서도 한 번에 읽히는 크기로
- 말풍선은 손으로 그린 불규칙한 원형, 생각은 구름형

## 본편에 넣지 않는 것
- 에피소드 제목
- 컷 번호
- 다른 컷의 문구
- (표지 규칙은 `brand/05_EPISODE_TEMPLATE.md`의 「표지와 본편은 다르다」)

## 시선 흐름
- 왼쪽 위 → 오른쪽 아래
- 표지는 중앙 집중 구도

## 비교·대조 컷
- 화면을 세로 점선으로 이등분해 좌/우 대비
- 각 반쪽에 키워드 1줄 + 상징 그림 1개
- **남용 금지** — 대비 구도는 설명적으로 흐르기 쉽다. 한 에피소드에 한 번까지

## 색감
- 항상 일정. 에피소드 내 색 규칙 유지
- 채도 과하지 않게

## 마지막 컷 (여운 장)
- 결론을 강요하지 않는다
- 텍스트 0~1문장. **0이 기본이다**
- 여백이 화면의 60% 이상
- 소품으로 잔잔한 움직임을 암시하되, **상징물을 새로 만들지 않는다**
  (감정이 흔들린다고 커튼·낙엽·바람·파도를 넣지 않는다)
- 마지막 컷의 내용 규칙은 `brand/11_STORY_TYPES.md` 7장 — **삭제 테스트 필수**
