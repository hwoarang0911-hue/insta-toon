# 이미지 생성 규칙 (공통)

모든 컷 생성 시 지켜야 할 공통 규칙. 도구별 프롬프트 포맷은 `pipeline/templates/03_render_prompts.md` 참조.

## 참조 이미지 원칙
1. 항상 `assets/character_sheet.png`를 참조 이미지로 첨부한다.
2. 같은 에피소드 안에서는 **직전에 생성된 컷**도 함께 첨부해 연속성을 유지한다.
3. 그림체가 흔들리면 `assets/samples/`의 샘플을 스타일 참조로 추가한다.

## 표지 합성 절차 (실사 배경 예외)
표지(1장)는 컷1~4·여운과 만드는 방식이 다르다 (`brand/03_DRAWING_STYLE.md` 표지 예외).

1. 에피소드 실제 장소의 사진을 준비한다 (직접 촬영 또는 출처가 분명한 사진)
2. 캐릭터만 **배경 없이(흰 배경 또는 투명)** 생성한다 — 그림체·표정 규칙은 동일, character_sheet.png 첨부
3. 사진 편집 툴에서 캐릭터 컷아웃을 사진 위에 배치하고 흰 테두리를 살려 스티커처럼 보이게 한다
4. 표지 문구를 손글씨 느낌 폰트로 얹는다

컷1~4·여운은 이 예외 없이 기존 방식(배경도 손그림) 그대로 유지한다.

## 일관성 체크리스트 (생성 후 매 컷 확인)
- [ ] 머리: 어깨 닿는 검은 웨이브 단발인가
- [ ] 눈: 작은 점 눈, 담백한 표정인가 (표정 4종 안인가)
- [ ] 옷: 무지 긴팔 상의 + 통바지, 에피소드 내내 동일한가
- [ ] 선: 만년필 스케치 느낌, 불규칙한 선인가
- [ ] 색: 흑백(또는 정해진 파스텔 1~2색)인가
- [ ] 배경: 미니멀하고 여백이 충분한가 (**표지는 예외** — 실사 배경 콜라주)
- [ ] 텍스트: 한글이 정확하게 렌더링되었는가 (오타 시 재생성 또는 후보정)

## 텍스트 렌더링
- 나노바나나(Gemini): 한글 텍스트를 이미지에 직접 렌더링 요청 가능. 오타 발생 시 해당 컷만 재생성.
- GPT(이미지 생성): 한글 렌더링이 불안정하면 텍스트 없이 생성 후 후작업으로 삽입.
- 텍스트 후삽입 시 폰트: 손글씨 계열 (예: 나눔손글씨 붓, KCC은영체 등 상업용 무료 폰트)

## 금지
- 새 캐릭터를 허락 없이 추가하지 않는다 (군중은 실루엣만)
- 캐릭터·옷·선 스타일·색감을 임의로 바꾸지 않는다
- 매 화 같은 세계에서 이어지는 느낌을 깨뜨리지 않는다
