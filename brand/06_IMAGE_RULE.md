# 이미지 생성 규칙 (공통)

> 이미지 생성 시 **함께 읽는 문서**:
> `brand/02_CHARACTER.md` (외형) + `brand/11_STORY_TYPES.md` (장면·구도)
> + 해당 에피소드 `02_storyboard.md` + 해당 컷 프롬프트
>
> 도구별 프롬프트 포맷은 `pipeline/templates/03_render_prompts.md` 참조.

## 참조 이미지 원칙
1. 항상 `assets/character_sheet.png`를 참조 이미지로 첨부한다.
2. 같은 에피소드 안에서는 **직전에 생성된 컷**도 함께 첨부해 연속성을 유지한다.
3. 그림체가 흔들리면 `assets/samples/`의 샘플을 스타일 참조로 추가한다.

## 프롬프트 작성 우선순위

**감정이나 분위기보다 먼저 물리적 장면을 명확하게 정의한다.**
아래 순서대로 쓴다. 순서를 바꾸면 분위기만 남고 장면이 사라진다.

```
1. 캐릭터 시트 일관성
2. 현재 컷에서 실제로 보이는 행동   ← 여기가 프롬프트의 몸통
3. 카메라 구도와 거리
4. 장소와 필수 배경
5. 생활 디테일
6. 표정
7. 대사
8. 스타일
9. 금지 요소
```

## 모든 컷 프롬프트에 반드시 포함하는 문장

```
Generate one standalone image containing only this single scene.
Do not create a comic grid, collage, split screen, or multiple moments.
Do not include text from any other panel.
```

한국어판:

```
이 한 장면만 담은 독립된 이미지 하나를 만들어줘.
만화 격자, 콜라주, 분할 화면, 여러 순간을 한 장에 넣지 마.
다른 컷의 문구를 넣지 마.
```

## 제거할 것 (프롬프트에서 자주 나오는 문제)
- 감정 형용사의 반복 ("쓸쓸한, 고요한, 아련한…")
- 추상적 분위기 설명 과잉
- 불필요한 상징물
- 모든 컷에 동일한 캐릭터 중심 구도
- 장면에 없는 오브젝트 추가
- 대사와 장면 불일치
- 이전 컷의 제목·문구가 다음 컷에 반복되는 문제
- 한 이미지에 여러 장면 결합
- 캐릭터 비율과 얼굴이 컷마다 변하는 문제

## 표지 합성 절차 (실사 배경 예외)
표지(1장)는 본편과 만드는 방식이 다르다 (`brand/05_EPISODE_TEMPLATE.md` 「표지와 본편은 다르다」).

1. 에피소드 실제 장소의 사진을 준비한다 (직접 촬영 또는 출처가 분명한 사진)
2. 캐릭터만 **배경 없이(흰 배경)** 생성한다 — 외형 규칙은 동일, character_sheet.png 첨부
3. 사진 편집 툴에서 캐릭터 컷아웃을 사진 위에 배치하고 흰 테두리를 살려 스티커처럼 보이게 한다
   - **원근과 빛을 사진에 맞춘다** (캐릭터가 떠 보이면 실패)
   - **제목 스티커와 캐릭터 누끼가 겹치지 않게** 배치한다
4. 표지 문구를 손글씨 느낌 폰트로 얹는다

본편(컷1~4·여운)은 이 예외 없이 배경도 손그림으로 그린다.

## 일관성 체크리스트 (생성 후 매 컷 확인)

**캐릭터** (`brand/02_CHARACTER.md`)
- [ ] 머리: 어깨 닿는 검은 웨이브인가
- [ ] 눈: 작은 점 눈, 표정 4종 안인가 (얼굴 안 보이는 컷은 해당 없음)
- [ ] 옷: 무지 긴팔 상의 + 통바지, 에피소드 내내 동일한가
- [ ] 등신 비율이 앞 컷과 같은가
- [ ] 소지품·의상에 실존 브랜드 로고·워드마크가 없는가

**그림** (`brand/03_DRAWING_STYLE.md`)
- [ ] 선: 만년필 스케치, 두껍고 불규칙한 선인가
- [ ] 색: 흑백(또는 정해진 파스텔 1~2색), 배경색 흰색(#ffffff)인가
- [ ] 비율: 4:5(1080×1350)인가
- [ ] 컷 가장자리에 테두리선(외곽선)이 있는가

**장면** (`brand/11_STORY_TYPES.md`)
- [ ] 한 이미지에 한 장면만 있는가 (격자·콜라주 아님)
- [ ] 콘티의 `visible_action`이 실제로 보이는가
- [ ] 카메라 거리가 콘티와 같은가
- [ ] 생활 디테일이 들어갔는가
- [ ] 본편 컷에 제목·컷 번호·다른 컷 문구가 없는가
- [ ] 텍스트: 크고, 한글이 정확하게 렌더링되었는가

## 텍스트 렌더링
- 나노바나나(Gemini): 한글 텍스트를 이미지에 직접 렌더링 요청 가능. 오타 발생 시 해당 컷만 재생성.
- GPT(이미지 생성): 한글 렌더링이 불안정하면 텍스트 없이 생성 후 후작업으로 삽입.
- 텍스트 후삽입 시 폰트: 손글씨 계열 (나눔손글씨 붓, KCC은영체 등 상업용 무료 폰트)

## 금지
- 새 캐릭터를 허락 없이 추가하지 않는다 (군중은 실루엣만)
- 캐릭터·옷·선 스타일·색감을 임의로 바꾸지 않는다
- 매 화 같은 세계에서 이어지는 느낌을 깨뜨리지 않는다
