# [ep002] 물을 그린 피아니스트 — 스토리 콘티

> ## ⚠️ legacy — 규칙 정립 이전 구조
> 이 화는 `brand/11_STORY_TYPES.md` 이전에 만들어졌다. 다음 문제가 남아 있다:
> **전 컷 독백(무대사 컷 없음) · 사색형 편중 · 구도 반복(중경 위주) · 마지막 컷이 의미를 설명함.**
> 컷 구성과 장소는 참고해도 되지만 **톤과 구조는 따라 쓰지 않는다.**
> 현행 기준작은 `episodes/ep004_taste_and_prompt/`다.


> **목소리** — 20대 여성의 말, 평어체 위주. 문장은 완결형, 독백은 보고가 아님.
> **서사** — 컷2에서 던진 질문("왜 다 다르게 들리지")을 컷3에서 눈앞에 보고, 컷4에서 답한다.
> 리스트의 생애 정보·작곡가 초상 없음. 선율과 물의 결로만 표현한다.

---

## 1장 — 표지 (훅)
- **화면 텍스트**: "물을 그린 피아니스트"
- **장면**: 루아 상반신. 이어폰을 낀 채 고개를 살짝 기울여 아래를 내려다본다. 화면 하단 1/4에 잔잔한 물결 선, 그 사이에 작은 음표 두세 개
- **카메라**: 상반신 클로즈업
- **표정**: 생각 중
- **구도 메모**: 중앙 집중. 물결 선이 화면 하단에서 잔잔히 출렁임

## 2장 — 컷1 (기 · 마음에 뭔가 걸린다)
- **장면**: 해질녘 노들섬. 걷다 멈춘 루아가 강가 난간에 살짝 기대어 한강을 내려다본다. 이어폰, 어깨에 토트백. 강 건너 도시 스카이라인은 아주 가는 선으로 멀리
- **카메라**: 전신 (강과 하늘 포함)
- **표정**: 생각 중
- **대사/텍스트**: 내레이션(상단)
  > "퇴근길에 그냥 노들섬에서 내렸다.
  > 듣고 있던 피아노가 자꾸 물소리처럼 들렸다."
- **구도 메모**: 강은 화면 하단 절반, 하늘은 넓게. 해질녘의 옅은 빛

## 3장 — 컷2 (승 · 질문이 된다)
- **장면**: 걷는 루아의 옆모습. 이어폰에서 흘러나온 선율 한 줄이 왼쪽에서 오른쪽으로 흐르며 모양을 바꾼다 — 낮게 가라앉는 물결 → 잘게 반짝이는 물방울 → 위로 솟는 물줄기
- **카메라**: 미디엄 (옆모습, 걷는 중)
- **표정**: 생각 중
- **대사/텍스트**:
  - 내레이션(상단)
    > "리스트가 쓴 곡에는 물에 대한 이야기가 유난히 많다.
    > 호수도 있고, 샘도 있고, 분수도 있다."
  - 하단 작게(**질문**) "그런데 이상하게 하나도 안 비슷하다. 왜 다 다르게 들리지?"
- **구도 메모**: 선율=물의 변형이 왼쪽에서 오른쪽으로 흐르는 한 줄. 초상·라벨 없음

## 4장 — 컷3 (전 · 눈앞에 답이 나타난다)
- **장면**: 고개를 든 루아. 시선이 강으로 향한다. 강 수면의 결이 왼쪽에서 오른쪽으로 계속 달라진다 — 잔잔한 수평 물결 → 바람이 지나가는 비스듬한 자국 → 빛에 잘게 반짝임
- **카메라**: 허리 위, 강을 마주 보는 구도
- **표정**: 생각 중 (고개를 든 순간)
- **대사/텍스트**: 내레이션(상단)
  > "그러다 문득 고개를 들었는데, 강이 아까랑 좀 달라 보였다.
  > 바람이 한 번씩 불 때마다 물빛이 계속 바뀌고 있었다."
- **구도 메모**: 이 에피소드의 가장 조용한 컷. 수면의 결 변화를 해칭 방향으로 (왼쪽 가로 해칭 → 오른쪽 짧고 촘촘한 해칭). **3장 선율의 변화와 같은 리듬으로 그려 두 컷이 겹쳐 보이게 한다**

## 5장 — 컷4 (결 · 질문이 풀린다)
- **장면**: 강을 바라보는 루아의 옆모습(허리 위), 옅은 미소. 수면은 여전히 결이 살아 움직이는 채로
- **카메라**: 허리 위, 옆모습
- **표정**: 좋아하는 순간 → 미소
- **대사/텍스트**:
  - 내레이션(상단)   ← **컷2의 질문에 대한 대답**
    > "아, 물은 원래 계속 다른 거구나.
    > 같은 강이어도 볼 때마다 다르다."
  - 하단 작게 "그 사람도 이렇게 오래 앉아서 물을 봤겠지."
- **구도 메모**: 배경은 강과 하늘만, 여백 크게

## 6장 — 여운
- **장면**: 멀리서 본 노들섬. 난간에 기대 강을 보는 루아의 작은 뒷모습. 해가 거의 저문 하늘, 별 하나
- **카메라**: 원경, 뒷모습
- **표정**: 보이지 않음
- **대사/텍스트**: 상단 여백에 "해가 다 질 때까지 그냥 좀 더 서 있었다."
- **구도 메모**: 여백 60% 이상. 물결 선은 최소한으로, 아주 잔잔하게

- [x] **「이미지에 들어가는 글자」 표를 채웠는가** — 8개 항목 기재
- [x] 표지 문장이 한 호흡에 읽히고 궁금증 유발 — "물을 그린 피아니스트"
- [x] 각 컷 = 감정 하나 + 행동 하나
- [x] 대사가 자연스럽게 읽히는가 — 글자 수 대신 말의 흐름으로 판단
- [x] 텍스트 > 그림인 컷 없음
- [x] **컷4의 대답이 컷2의 물음에 대응하는가** — "왜 다 다르게 들리지?" ↔ "물은 원래 계속 다른 거구나" ✓
- [x] **컷3의 목격이 컷2의 질문과 같은 것에 관한 것인가** — 둘 다 '물이 다르다'는 것
- [x] **독백이 보고가 아닌가** — `~싶었다` `~생각했다` 없음
- [x] **말끝 흐리기 중독이 없는가** — 7줄 모두 완결 문장
- [x] **평어체 위주인가** — `~더라고` `~거든` `~잖아` 없음. 혼잣말(`~지?`)·알아챔(`~구나`)만 자연스럽게
- [x] 마지막 장은 여운 — 깨달았기 때문에 하게 된 행동 (정형 질문형 아님)
- [x] 표정 4종 안에서 해결 — 생각 중 / 좋아하는 순간 / 미소
