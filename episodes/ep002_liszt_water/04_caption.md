# [ep002] 물을 그린 피아니스트 — 캡션·해시태그

## 인스타그램 캡션 (복사해서 사용)

```
리스트 곡에는 물이 참 많이 나온다. 호수 아니면 샘, 아니면 분수다.
그런데 다 다르게 들려서 왜 그럴까 했다.
노들섬에서 고개를 들었더니, 바람이 불 때마다 강 물빛이 계속 바뀌고 있었다.

🎵 오늘의 곡
리스트 — 순례의 해 中
· 발렌슈타트 호수에서 (고요해지고 싶은 날)
· 샘가에서 (마음이 반짝이는 날)
· 에스테 별장의 분수 (빛이 필요한 날)

물은 볼 때마다 달랐다.

#레스트노트 #루아 #루아의플레이리스트
#인스타툰 #감성툰
#클래식음악 #클래식추천 #리스트 #순례의해 #노들섬 #한강
```

## 업로드 메모
- 권장 시간대: 일요일 오후 (트랙 A 정례 슬롯)
- 릴스 재활용 계획: 6장 슬라이드 + '샘가에서' 도입부 음원.
  4장(강의 결이 변하는 컷)에서 물결 사운드가 겹치는 편집이 효과적일 것
