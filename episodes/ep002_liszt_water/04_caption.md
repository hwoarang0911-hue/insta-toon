# [ep002] 물을 그린 피아니스트 — 캡션·해시태그

## 인스타그램 캡션 (복사해서 사용)

```
리스트의 순례의 해를 듣다가 알았다. 이 사람은 평생 물가로 돌아왔구나.
청년의 호수는 낮고 고요했고, 노년의 분수는 빛을 향해 솟았다.
물이 변한 게 아니라, 바라보는 마음이 변한 것이었다.

🎵 오늘의 곡
리스트 — 순례의 해 中
· 발렌슈타트 호수에서 (고요해지고 싶은 날)
· 샘가에서 (마음이 반짝이는 날)
· 에스테 별장의 분수 (빛이 필요한 날)

오늘 당신의 물은 어떤 소리를 내나요?

#레스트노트 #루아 #루아의플레이리스트
#인스타툰 #감성툰
#클래식음악 #클래식추천 #리스트 #순례의해 #청계천
```

## 업로드 메모
- 권장 시간대: 일요일 오후 (트랙 A 정례 슬롯)
- 릴스 재활용 계획: 6장 슬라이드 + '샘가에서' 도입부 음원.
  3장(호수/분수 대비 컷)에서 '에스테 별장의 분수'로 음원이 전환되는 버전이 가장 효과적일 것
- 연계 메모: 세계관의 티볼리(에스테 별장)가 처음 언급된 에피소드.
  훗날 루아가 실제로 티볼리에 가는 여행 에피소드의 복선으로 활용 가능
