# [ep004] 커서만 십 분째 — 캡션·해시태그

> 본편은 빈 입력창 옆에 붙인 엽서에서 끝난다. 캡션은 **그 뒤에 있었던 일**이다.
> 본편 문장을 옮기지 않고, **본편의 의미를 설명하지도 않는다.**

## 인스타그램 캡션 (복사해서 사용)

```
어디서 산 건지는 기억이 안 난다. 그것만 계속 자리를 옮겨 다녔다.
그날은 그냥 컴퓨터를 껐다.

다음 날 보니까 좀 삐뚤게 붙어 있었다. 그냥 뒀다.

#레스트노트 #루아
#인스타툰 #감성툰 #일상툰
#혼자만의시간 #책상 #엽서
```

**마무리 방식**: 작은 행동 한 줄 (`pipeline/templates/04_caption.md`의 표).
ep003은 '감각·행동 한 줄', ep002는 '다시 해본 일'이었다. 다음 화는 여백을 써본다.

## 본편과의 관계
- 본편이 끝난 지점: 빈 입력창 옆에 붙인 엽서
- 캡션이 이어가는 것: **그 뒤에 실제로 한 일** — 컴퓨터를 껐고, 다음 날 삐뚤어진 걸 봤고, 그냥 뒀다
- 본편에 없던 것: 출처를 기억 못 한다는 것, 이사·정리 때마다 그것만 챙겼다는 것, 다음 날의 시간

## 자기 점검
- [x] 본편 문장 복사 없음
- [x] 곡 추천 없음
- [x] 경고 표현 스캔 — 없음
- [x] **캡션이 본편의 의미를 설명하지 않음** — "취향", "AI", "만들고 싶은 것" 같은 말이 한 번도 안 나온다.
      주제를 정리하려는 문장이 없다
- [x] 감정 레벨 유지 — 캡션에서도 1을 넘지 않는다
