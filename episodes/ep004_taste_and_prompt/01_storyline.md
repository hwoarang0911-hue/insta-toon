# [ep004] 커서만 십 분째 — 스토리라인

> `brand/11_STORY_TYPES.md` 6장의 STEP 1~5.
> 이 화는 새 파이프라인의 **검증용**으로 만들었다. 주제가 대놓고 관념적이라
> 예전 규칙이었다면 REFLECTION + 마지막 컷 교훈으로 끝났을 소재다.

## 입력 주제
> AI를 쓸수록 개인의 취향이 중요해진다는 생각

---

## STEP 1. 스토리 유형 선택

- **주 유형**: TASTE (취향형)
- **보조 유형**: OBSERVE
- **왜 이 유형인가**: 사건 자체가 "여러 개 중에 하나를 고르는 일"이다.
  AI 결과물 여러 장 → 아무것도 안 고름 → 엽서 한 장을 고름.
  TYPE 04의 기본 구조(대상을 만남 → 감각이 시선을 끔 → 조금 더 머묾 → 다시 선택하는 행동으로 취향이 드러남)와 그대로 맞는다
- **사색은 어디에 있나**: 화면 속 결과물을 스크롤하며 "다 괜찮은데"라고 느끼는 데서 시작해,
  손에 잡힌 낡은 엽서에서 **"삼 년째 안 버렸네"** 로 닫힌다.
  **관념("취향이 중요하다")에서 출발하지 않고, 많은 것과 하나를 겪는 동안 알아챈다**
- **교훈으로 넓히지 않는다**: "만들어주는 게 많을수록 ~" 류의 문장을 쓰지 않는다.
  "취향"이라는 말도 스크립트에 넣지 않는다. 대비만 보여주고 끝낸다

**로테이션 확인** (`brand/11_STORY_TYPES.md` 19장)
- 직전 화들의 주 유형: ep003 CULTURE / ep002 REFLECTION
- [x] 동일 유형 3회 연속 아님
- [x] 사색형 연속 게시 아님
- [x] 조합이 지양 목록(18장)에 없음 — TASTE+OBSERVE
- [~] "직전이 CULTURE면 OBSERVE 또는 RELATE" — **참고치라 그대로 간다.**
      ep003과 장소(카페/방)·시간(오후/밤)·구도가 충분히 달라 같은 틀의 반복이 아니다.
      사이에 관찰형 한 화를 넣으면 리듬은 더 좋아진다

## STEP 2. 추상 주제를 구체적 순간으로 변환

| | 내용 |
|---|---|
| 나쁜 입력 (추상) | AI를 쓸수록 개인의 취향이 중요해진다 |
| → 좋은 입력 (구체) | 늦여름 밤 열한 시, 이미지 생성 AI 입력창 앞에서 십 분째 아무것도 못 치다가 책상 옆 엽서 한 장을 뽑아 모니터 옆에 붙였다 |

**Core Moment (한 문장)**
> 늦여름 밤 열한 시, 이미지 생성 AI 입력창 앞에서 십 분째 아무것도 못 치다가 책상 옆 엽서 한 장을 뽑아 모니터 옆에 붙였다.

- **주제를 문장으로 말하지 않는다.** "취향"이라는 말은 스크립트 어디에도 나오지 않는다
- 빈 입력창과 붙여둔 엽서를 나란히 보여주는 것으로 끝낸다

## 컷 흐름 (초안)

TYPE 04 기본 구조: 대상을 만남 → 감각이 시선을 끔 → 조금 더 머묾 → 다시 선택하는 행동

| 장 | 이 컷에서 일어나는 일 |
|---|---|
| COVER | 어두운 방, 모니터 빛만 받는 루아와 빈 입력창 (CUT 1의 장면) |
| CUT 1 | 입력창에 커서만 깜빡인다. 키보드 위에 손만 올려두고 있다 |
| CUT 2 | 결과 이미지 여러 장이 뜬다. 스크롤만 하고 아무것도 안 고른다 — "다 괜찮은데" |
| CUT 3 | 의자를 돌린다. **책상 아래에서 발이 흔들린다** ← 생활 디테일 · 무대사 |
| CUT 4 | 엽서 한 장을 뽑아 든다 — **"삼 년째 안 버렸네"** ← 이 화의 알아챔 |
| CLOSING | 엽서를 붙이고 입력창은 그냥 비워둔다 (알아챘기 때문에 하게 된 행동) |
