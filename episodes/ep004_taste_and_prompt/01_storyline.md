# [ep004] 커서만 십 분째 — 스토리라인

## 입력 주제
> AI를 쓸수록 개인의 취향이 중요해진다는 생각

> **이 화는 새 파이프라인의 검증용으로 만들었다.** (`brand/11_STORY_TYPES.md` 도입 후 첫 화)
> 주제가 대놓고 관념적이라 예전 규칙이었다면 REFLECTION + 마지막 컷 교훈으로 끝났을 소재다.
> 13단계를 그대로 밟아 **TASTE 유형 · 감정 레벨 1 · 무대사 3컷**으로 나왔다.

|---|---|
| 추상 주제 | AI를 쓸수록 개인의 취향이 중요해진다 |
| → 실제 장소 | 루아의 방, 책상 |
| → 특정 시간 | 늦여름 밤 11시, 방 불은 끄고 모니터만 켜둔 상태 |
| → 캐릭터의 행동 | 이미지 만들어주는 AI 입력창을 띄워놓고 뭘 칠지 못 정하고 있다 |
| → 작은 변화나 사건 | 결국 아무것도 안 치고, 책상 옆 엽서꽂이에서 오래된 엽서 한 장을 뽑아 모니터 옆에 붙인다 |

**변환 결과 한 줄**
> 늦여름 밤 열한 시, 이미지 생성 AI 입력창 앞에서 십 분째 아무것도 못 치다가 책상 옆 엽서 한 장을 뽑아 모니터 옆에 붙였다.

- **주제를 문장으로 말하지 않는다.** "취향이 중요하다"는 말은 어디에도 나오지 않는다
- 빈 입력창과 붙여둔 엽서를 나란히 보여주는 것으로 끝낸다

### 유형 선택 근거
- **왜 TASTE인가**: 사건 자체가 "여러 개 중에 하나를 고르는 일"이다. AI가 만든 결과물 여러 장 → 아무것도 안 고름 → 엽서 한 장을 고름. TASTE의 컷 흐름과 그대로 맞는다
- **왜 REFLECTION이 아닌가**: 주제가 관념적이라 REFLECTION으로 가기 쉬웠다. 그러면 컷4에서 "고를 게 있다는 게 결국 내 취향이구나" 같은 문장이 나오고, 그게 정확히 고치려던 문제다. TASTE로 놓으면 **고르는 행동 자체가 결론을 대신한다**
- **왜 OBSERVE 보조인가**: 화면 속 결과물들을 그냥 보는 컷이 하나 필요했다
- 직전 두 화: ep003 CULTURE / ep002 REFLECTION → **겹치지 않음**

## 컷 흐름

**TASTE 흐름**: 여러 개 → 하나에 멈춤 → 만져봄 → 고름 → 쥔 손
(이 화에서는 마지막이 "쥔 손" 대신 "붙여둔 자리"로 끝난다)

| 장 | 이 컷에서 일어나는 일 (행동) |
|---|---|
| 표지 | 어두운 방, 모니터 빛만 받는 루아와 빈 입력창 (컷1의 장면) |
| 컷1 | 입력창에 커서만 깜빡인다. 키보드 위에 손만 올려두고 있다 |
| 컷2 | 아무 단어나 쳐서 결과 이미지 여러 장이 뜬다. 그냥 본다 |
| 컷3 | 의자를 돌린다. **책상 아래에서 발이 흔들린다** ← 생활 디테일 · 무대사 |
| 컷4 | 책상 옆 엽서꽂이에서 엽서 한 장을 뽑아 든다 |
| 여운 | 모니터 옆에 엽서가 붙어 있다. 입력창은 그대로 비어 있다 |

- 마지막 컷에 독백 없음. **빈 입력창과 엽서를 한 화면에 두는 것으로 끝난다**
