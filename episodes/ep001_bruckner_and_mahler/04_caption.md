# [ep001] 브루크너와 말러 — 캡션·해시태그

## 인스타그램 캡션 (복사해서 사용)

```
브루크너를 듣다가 말러를 들으면, 다른 세계에 온 것 같았다.
한 사람은 영원을 보았고, 한 사람은 지금 여기를 보았다.
오늘의 내 마음은 어느 쪽이었을까.

🎵 오늘의 곡
브루크너 — 교향곡 7번, 2악장 Adagio (고요해지고 싶은 날)
말러 — 교향곡 1번 '거인', 3악장 (복잡하고 살아있는 날)

당신의 마음은 지금 어디에 머물고 있나요?

#레스트노트 #쉼이 #쉼이의플레이리스트
#인스타툰 #감성툰
#클래식음악 #클래식추천 #브루크너 #말러 #혼자만의시간
```

## 업로드 메모
- 권장 시간대: 일요일 오후
- 릴스 재활용 계획: 6장 슬라이드 + 브루크너 7번 Adagio 도입부 음원. 마지막 장에서 말러로 음원 전환하는 버전도 실험 가능
