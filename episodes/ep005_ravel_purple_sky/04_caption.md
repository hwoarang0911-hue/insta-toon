# [ep005] 낮도 밤도 아닌 노래 — 캡션·해시태그

> 본편은 손바닥에 남은 사슬 자국을 보는 데서 끝난다. 캡션은 **그 뒤에 있었던 일**이다.
> 본편 문장을 옮기지 않고, **본편의 의미를 설명하지도 않는다.**

## 인스타그램 캡션 (복사해서 사용)

```
집에 오는 길에 하늘을 한 번 더 봤다.
이제는 완전히 까매져 있었다.

볼레로는 그때까지도 다 안 끝나 있었다.

#레스트노트 #루아 #루아의플레이리스트
#인스타툰 #감성툰
#클래식음악 #클래식추천 #라벨 #볼레로
```

**마무리 방식**: 다시 해본 일 (`pipeline/templates/04_caption.md`의 표).
다음 화는 감각 한 줄 / 여백 중에서.

## 본편과의 관계
- 본편이 끝난 지점: 손바닥의 사슬 자국을 보는 자리
- 캡션이 이어가는 것: **그 뒤에 실제로 한 일** — 집에 가는 길에 하늘을 한 번 더 봤다
- 본편에 없던 것: 하늘이 완전히 까매졌다는 것, 볼레로가 그렇게 길다는 것(곡이 끝나기 전에
  집에 도착했다)
- **본편의 알아챔을 다시 말하지 않는다.** "이 색 하나였구나"를 캡션에서 반복하거나
  풀어서 설명하지 않았다

## 자기 점검
- [x] 본편 문장 복사 없음
- [x] 곡 추천 없음 (곡명은 본문에서 이미 나왔고, 캡션에서 큐레이션하지 않는다)
- [x] **캡션이 본편의 의미를 설명하지 않음** — "색이란", "음악이란" 같은 정리 문장이 없다
- [x] 작품 해설 없음
- [x] 감정 레벨 유지 — 1을 넘지 않는다
- [x] 경고 표현 0건 (`결국` `어쩌면` `문득` `그제야` `우리 모두` `인생` `진정한` `소중한` `깨달았다` `본질` `나다운` `행복이란`)
- [x] 생활 디테일이 본편 안에서만 쓰이고 캡션에서 상징으로 확장되지 않음

## 업로드 메모
- 권장 시간대: 평일 저녁 8~9시 (하늘색이 실제로 바뀌는 시간대와 겹치게)
- 릴스 재활용 계획: 6장 슬라이드 + 라벨 「물의 유희」에서 「볼레로」로 넘어가는 지점을 그대로 음원으로.
  전환되는 순간이 컷2와 정확히 맞물리게 편집
- 브랜드·매장 태그 없음 (동네 놀이터는 특정 상호가 없는 공공장소)
