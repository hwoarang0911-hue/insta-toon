# [ep003] 쉬는 악장인 줄 알았는데 — 캡션·해시태그

> 본편은 다 식은 커피컵을 쥔 손에서 끝난다. 캡션은 **그 뒤에 있었던 일**이다.
> 본편 문장을 옮기지 않고, **본편의 의미를 설명하지도 않는다.**

## 인스타그램 캡션 (복사해서 사용)

```
나오니까 밖은 아까랑 똑같았다.

버스 기다리면서 1악장을 틀어봤는데 거기도 밑에 뭐가 있었다.

가방끈은 집에 올 때까지 안 올렸다.

#레스트노트 #루아 #루아의플레이리스트
#인스타툰 #감성툰
#클래식음악 #클래식추천 #비발디 #사계
```

**마무리 방식**: 다시 해본 일 (`pipeline/templates/04_caption.md`의 표).
다음 화는 감각 한 줄 / 여백 중에서.

## 본편과의 관계
- 본편이 끝난 지점: 그 부분만 계속 듣느라 커피가 다 식은 자리
- 캡션이 이어가는 것: **그 뒤에 실제로 한 일** — 나왔고, 1악장을 틀어봤다
- 본편에 없던 것: 1악장에도 밑에 뭐가 있었다는 사실, 가방끈을 끝까지 안 올렸다는 것
- **본편의 알아챔을 다시 말하지 않는다.** "안 듣고 있었구나"를 캡션에서 반복하거나
  풀어서 설명하지 않았다

## 자기 점검
- [x] 본편 문장 복사 없음
- [x] 곡 추천 없음 (곡명은 본문에서 이미 나왔고, 캡션에서 큐레이션하지 않는다)
- [x] **캡션이 본편의 의미를 설명하지 않음** — "듣는다는 건", "음악이란" 같은 정리 문장이 없다
- [x] 작품 해설 없음 — "밑에 뭐가 있었다"까지만. 용어를 쓰지 않았다
- [x] 감정 레벨 유지 — 1을 넘지 않는다
- [x] 경고 표현 0건 (`결국` `어쩌면` `문득` `그제야` `우리 모두` `인생` `진정한` `소중한` `깨달았다` `본질` `나다운` `행복이란`)
- [x] 생활 디테일(가방끈)이 본편에서 캡션까지 이어진다 — 주제의 상징으로 쓰지 않았다

## 업로드 메모
- 권장 시간대: 일요일 오후 (트랙 A 정례 슬롯)
- 릴스 재활용 계획: 6장 슬라이드 + 비발디 「사계 - 여름」 2악장을 음원으로.
  캡션에 곡명을 적지 않고 음원 태그로만 노출한다.
  4장(창밖을 보는 무대사 컷)에서 음량을 그대로 두면 아래 깔린 소리가 오래 남는다
- **브랜드명 해시태그는 넣지 않았다.** 매장 이름을 태그하면 광고처럼 읽힌다
  (`brand/09_GROWTH_STRATEGY.md` — 광고성 태그 남발 금지)
