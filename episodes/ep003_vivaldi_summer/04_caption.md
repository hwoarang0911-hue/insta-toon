# [ep003] 쉬는 악장인데 왜 안 쉬어지지 — 캡션·해시태그

> 본편은 볼륨을 줄인 손에서 끝난다. 캡션은 **그 뒤에 있었던 일**이다.
> 본편 문장을 옮기지 않고, **본편의 의미를 설명하지도 않는다.**

## 인스타그램 캡션 (복사해서 사용)

```
그 자리에서 한 시간쯤 더 있었다.
나가려고 일어나니까 그제서야 조용한 것 같았다.

집에 와서 같은 악장을 다시 틀었는데 이번엔 별로 안 거슬렸다.

#레스트노트 #루아 #루아의플레이리스트
#인스타툰 #감성툰
#클래식음악 #클래식추천 #비발디 #사계
```

**마무리 방식**: 다시 해본 일 (`pipeline/templates/04_caption.md`의 표).
다음 화는 감각 한 줄 / 여백 중에서.

## 본편과의 관계
- 본편이 끝난 지점: 볼륨을 줄이고 둘 다 듣게 된 자리
- 캡션이 이어가는 것: **그 뒤에 실제로 한 일** — 한 시간 더 있었고, 집에 와서 다시 틀었다
- 본편에 없던 것: 나가려고 일어난 순간, 집에서 다시 들었을 때는 안 거슬렸다는 사실

## 자기 점검
- [x] 본편 문장 복사 없음
- [x] 곡 추천 없음 (곡명은 본문에서 이미 나왔고, 캡션에서 큐레이션하지 않는다)
- [x] **캡션이 본편의 의미를 설명하지 않음** — "쉼이란", "조용함이란" 같은 정리 문장이 없다
- [x] 감정 레벨 유지 — 1을 넘지 않는다
- [x] 경고 표현 — "그제서야"는 `그제야`의 구어형이라 경고 목록에 걸린다.
      여기서는 **깨달음을 강조하는 자리가 아니라 일어선 시점을 가리키는 시간 부사**로 썼다.
      거슬리면 "일어나니까 좀 조용한 것 같았다"로 바꾼다

## 업로드 메모
- 권장 시간대: 일요일 오후 (트랙 A 정례 슬롯)
- 릴스 재활용 계획: 6장 슬라이드 + 비발디 「사계 - 여름」 2악장을 음원으로.
  캡션에 곡명을 적지 않고 음원 태그로만 노출한다.
  4장(카운터를 보는 컷)에 그라인더 소리를 겹치면 목격의 순간이 살아난다
- **브랜드명 해시태그는 넣지 않았다.** 매장 이름을 태그하면 광고처럼 읽힌다
  (`brand/09_GROWTH_STRATEGY.md` — 광고성 태그 남발 금지)
