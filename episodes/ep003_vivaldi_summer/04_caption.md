# [ep003] 3악장에서 딴생각 — 캡션·해시태그

> 본편은 테이블 위 컵과 빨대 비닐에서 끝난다. 캡션은 **그 뒤에 있었던 일**이다.
> 본편 문장을 옮기지 않고, **본편의 의미를 설명하지도 않는다.**

## 인스타그램 캡션 (복사해서 사용)

```
결국 3악장은 처음부터 다시 들었다.
두 번째에도 절반쯤에서 또 딴생각을 했다.

비 그칠 때까지 앉아 있다가 그냥 걸어서 왔다.

#레스트노트 #루아 #루아의플레이리스트
#인스타툰 #감성툰
#클래식음악 #클래식추천 #비발디 #사계 #홍대
```

**마무리 방식**: 감각·행동 한 줄 (`pipeline/templates/04_caption.md`의 표).
ep002는 '다시 해본 일'이었다. 다음 화는 여백 / 자기 삶에 대본 한 줄 중에서.

## 본편과의 관계
- 본편이 끝난 지점: 테이블 위 컵과 떼어놓은 빨대 비닐, 가늘어진 비
- 캡션이 이어가는 것: **그 뒤에 실제로 한 일** — 곡을 다시 틀었고, 또 딴생각했다
- 본편에 없던 것: 두 번째에도 똑같았다는 사실, 걸어서 돌아온 것
- **의미를 설명하지 않았다**: 딴생각한 게 좋았는지 아쉬웠는지 쓰지 않았다. 그냥 있었던 일만 적었다

## 자기 점검
- [x] 본편 문장 복사 없음
- [x] 곡 추천 없음
- [x] 경고 표현 스캔 — "결국"이 1회 있으나, 여기서는 **"그래서 어쨌든"의 생활 구어**로 쓰였고
      의미를 정리하는 접속사가 아니다. 문장을 정리하는 자리에 쓰였다면 삭제 대상
- [x] 캡션이 본편의 의미를 설명하지 않음
