# [ep003] 이 곡, 진짜 여름 같아? — 스토리 콘티

> **목소리** — 20대 여성의 말, 평어체 위주. 문장은 완결형, 독백은 보고가 아님.
> **서사** — 컷2에서 던진 질문("근데 왜 이렇게까지 참았다가 터지지?")을 컷3에서 눈앞에 보고, 컷4에서 답한다.
> 비발디의 생애 정보·작곡가 초상 없음. 곡의 구조(고요→폭풍)와 실제 날씨의 결로만 표현한다.

---

## 1장 — 표지 (훅)
- **화면 텍스트**: "이 곡, 진짜 여름 같아?"
- **장면**: 루아 상반신. 이어폰이나 작은 스피커 쪽으로 살짝 고개를 기울이고 의심스러운 듯 듣고 있다
- **카메라**: 상반신 클로즈업
- **표정**: 생각 중
- **구도 메모**: 중앙 집중. 배경은 최소한 — 창문 프레임 정도만 옅게

## 2장 — 컷1 (기 · 마음에 뭔가 걸린다)
- **장면**: 무더운 토요일 오후, 집 안. 선풍기 앞에 앉은 루아가 스피커로 비발디의 「여름」을 틀어놓았다
- **카메라**: 미디엄 (선풍기, 스피커 포함)
- **표정**: 생각 중
- **대사/텍스트**: 내레이션(상단)
  > "토요일 오후, 선풍기 앞에 앉아서 비발디의 여름을 틀었다.
  > 근데 앞부분이 생각보다 너무 조용하다."
- **구도 메모**: 창밖 나뭇잎이 하나도 흔들리지 않는 정지된 느낌을 배경에 옅게. 배경 묘사는 짧게, 인물 위주

## 3장 — 컷2 (승 · 질문이 된다)
- **장면**: 눈을 감고 듣는 루아. 곡에 대한 생각이 이어진다
- **카메라**: 미디엄, 정면 또는 살짝 옆모습
- **표정**: 고민 중
- **대사/텍스트**:
  - 내레이션(상단)
    > "여름인데 폭풍이 갑자기 몰아친대.
    > 3악장 전까지는 계속 이렇게 잠잠하다."
  - 하단 작게(**질문**) "근데 왜 이렇게까지 참았다가 터지지?"
- **구도 메모**: 컷1의 '정지된 나뭇잎'을 다시 한번, 이번엔 창 전체로 넓게 — 고요함이 이어지고 있다는 느낌 강조

## 4장 — 컷3 (전 · 눈앞에 답이 나타난다)
- **장면**: 창가로 다가가 하늘을 올려다보는 루아. 하늘이 무겁게 가라앉아 있다가, 정말 갑자기 비가 쏟아지기 시작한다
- **카메라**: 허리 위, 창밖을 마주 보는 구도
- **표정**: 생각 중 (눈이 살짝 커진 정도 — 놀람은 이 이상 넘지 않는다)
- **대사/텍스트**: 내레이션(상단)
  > "그러다 창밖을 봤는데, 하늘이 아까부터 이상하게 무거웠다.
  > 그리고 정말 갑자기, 비가 쏟아지기 시작했다."
- **구도 메모**: 이 에피소드의 가장 조용한 컷. 2장의 정지된 나뭇잎이 이 컷에서 비바람에 흔들리는 모습으로 이어지게 그려서, 고요와 폭발이 같은 나무를 통해 이어져 보이게 한다

## 5장 — 컷4 (결 · 질문이 풀린다)
- **장면**: 창가 또는 처마 밑에서 쏟아지는 비를 바라보는 루아의 옆모습. 옅은 미소
- **카메라**: 허리 위, 옆모습
- **표정**: 좋아하는 순간 → 미소
- **대사/텍스트**:
  - 내레이션(상단)   ← **컷2의 질문에 대한 대답**
    > "아, 여름은 원래 이렇게 참다가 한 번에 쏟아지는 계절이구나."
  - 하단 작게 "나도 가끔은 이렇게 한 번씩 쏟아내도 되는 거였을까."
- **구도 메모**: 배경은 빗줄기와 젖은 창밖 풍경만, 여백 크게

## 6장 — 여운
- **장면**: 비가 그친 뒤, 창문을 열고 서 있는 루아의 작은 뒷모습
- **카메라**: 원경, 뒷모습
- **표정**: 보이지 않음
- **대사/텍스트**: 상단 여백에 "비가 그치고, 선선한 바람이 이마를 스치고 지나갔다."
- **구도 메모**: 여백 60% 이상. 젖은 풍경 위로 옅은 햇살 한 줄기, 빗방울 떨어지는 소품은 최소한으로

## Stage 2 체크리스트
- [x] **「이미지에 들어가는 글자」 표를 채웠는가** — 8개 항목 기재
- [x] 표지 문장이 한 호흡에 읽히고 궁금증 유발 — "이 곡, 진짜 여름 같아?"
- [x] 각 컷 = 감정 하나 + 행동 하나
- [x] 대사가 자연스럽게 읽히는가 — 글자 수 대신 말의 흐름으로 판단
- [x] 텍스트 > 그림인 컷 없음
- [x] **컷4의 대답이 컷2의 물음에 대응하는가** — "왜 이렇게까지 참았다가 터지지?" ↔ "참다가 한 번에 쏟아지는 계절이구나" ✓
- [x] **컷3의 목격이 컷2의 질문과 같은 것에 관한 것인가** — 둘 다 '참다가 터진다'는 것
- [x] **독백이 보고가 아닌가** — `~싶었다` `~생각했다` 없음
- [x] **말끝 흐리기 중독이 없는가** — 모든 문장이 완결형
- [x] **평어체 위주인가** — `~더라고` `~거든` `~잖아` 없음. 자문("~였을까")·알아챔("~구나")만 자연스럽게
- [x] 마지막 장은 여운 — 감각 한 줄로 마무리 (ep002는 '행동의 지속'이었으니 방식이 겹치지 않는다)
- [x] 표정 4종 안에서 해결 — 생각 중 / 고민 중 / 좋아하는 순간 / 미소
