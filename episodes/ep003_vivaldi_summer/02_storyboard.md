# [ep003] 조용한 데가 제일 안 조용하다 — 스토리 콘티

> **목소리** — 20대 여성의 말, 평어체 위주. 문장은 완결형, 독백은 보고가 아님.
> **서사** — 컷2에서 던진 질문("조용한 부분인데 왜 하나도 안 편하지?")을 컷3에서 눈앞에 보고, 컷4에서 답한다.
> 비발디의 생애 정보·작곡가 초상 없음. 유리 안팎의 대비로만 표현한다.
> **카페 브랜드명·로고는 어떤 컷에도 넣지 않는다.**

---

## 1장 — 표지 (훅)
- **화면 텍스트**: "이 곡, 조용한 데가 제일 안 조용하다"
- **장면**: 루아 상반신. 젖은 머리끝, 이어폰을 낀 채 유리창 쪽을 보고 있다
- **카메라**: 상반신 클로즈업
- **표정**: 생각 중
- **구도 메모**: 중앙 집중. 배경은 실사 사진(홍대 길가, 비 오는 날)과 합성 — `03_render_prompts.md` 0번 참고

## 2장 — 컷1 (기 · 마음에 뭔가 걸린다)
- **장면**: 소나기. 비를 맞은 루아가 홍대 길가 카페 문을 밀고 들어선다. 어깨와 토트백이 젖어 있다. 큰 유리창, 회색 콘크리트와 나무의 미니멀한 실내
- **카메라**: 전신 (문과 유리창 포함)
- **표정**: 생각 중
- **대사/텍스트**: 내레이션(상단)
  > "비를 쫄딱 맞고 홍대 길가 카페로 뛰어들었다.
  > 이어폰에선 아직 비발디의 여름이 흐르고 있었다."
- **구도 메모**: 밖은 빗줄기 해칭으로 어수선하게, 안은 선을 최소한으로 — 한 컷 안에서 밖과 안이 갈린다

## 3장 — 컷2 (승 · 질문이 된다)
- **장면**: 창가 자리에 앉은 루아. 컵을 앞에 두고 이어폰에 귀를 기울인다. 실내는 아주 조용하다
- **카메라**: 미디엄 (창가 테이블, 옆모습)
- **표정**: 고민 중
- **대사/텍스트**:
  - 내레이션(상단)
    > "자리에 앉으니 안은 조용하다.
    > 근데 곡은 느린 악장인데 저 아래에서 뭔가 계속 웅웅거린다."
  - 하단 작게(**질문**) "조용한 부분인데 왜 하나도 안 편하지?"
- **구도 메모**: 유리창은 아직 화면 가장자리에만 걸치게 — 아직 밖을 제대로 보지 않았다

## 4장 — 컷3 (전 · 눈앞에 답이 나타난다)
- **장면**: 고개를 돌려 창밖을 보는 루아. 유리 한 장 너머로 퍼붓는 비, 우산 쓴 사람들, 젖은 길이 그대로 다 보인다. 실내에는 소리가 없다
- **카메라**: 허리 위, 유리창을 마주 보는 구도
- **표정**: 생각 중
- **대사/텍스트**: 내레이션(상단)
  > "유리 한 장 너머로 비가 그대로 다 보인다.
  > 소리만 없고 나머지는 하나도 안 사라졌다."
- **구도 메모**: 이 에피소드의 가장 조용한 컷. **유리를 경계로 왼쪽(안)은 선이 거의 없고 오른쪽(밖)은 빗줄기 해칭이 빽빽하게** — 같은 화면에서 고요와 폭우가 붙어 있다

## 5장 — 컷4 (결 · 질문이 풀린다)
- **장면**: 여전히 창밖을 보는 루아의 옆모습, 옅은 미소. 컵을 두 손으로 감싸 쥐고 있다
- **카메라**: 허리 위, 옆모습
- **표정**: 좋아하는 순간 → 미소
- **대사/텍스트**:
  - 내레이션(상단)   ← **컷2의 질문에 대한 대답**
    > "아, 조용해져도 밖은 안 사라지니까 그렇구나.
    > 비발디는 그 조용함을 이렇게 써놨다."
  - 하단 작게 "잘 썼다는 말이 이제야 무슨 뜻인지 알겠다."
- **구도 메모**: 배경은 유리창과 빗줄기만, 여백 크게

## 6장 — 여운
- **장면**: 멀리서 본 창가 자리. 이어폰을 뺀 루아의 작은 뒷모습, 창밖을 보고 있다
- **카메라**: 원경, 뒷모습
- **표정**: 보이지 않음
- **대사/텍스트**: 상단 여백에 "이어폰을 뺐다. 창밖이 계속 그 곡이었다."
- **구도 메모**: 여백 60% 이상. 유리에 맺힌 물방울 몇 개만 소품으로

## Stage 2 체크리스트
- [x] **「이미지에 들어가는 글자」 표를 채웠는가** — 8개 항목 기재
- [x] 표지 문장이 한 호흡에 읽히고 궁금증 유발 — "조용한 데가 제일 안 조용하다"는 모순이 훅
- [x] 각 컷 = 감정 하나 + 행동 하나
- [x] 대사가 자연스럽게 읽히는가 — 글자 수 대신 말의 흐름으로 판단
- [x] 텍스트 > 그림인 컷 없음
- [x] **컷4의 대답이 컷2의 물음에 대응하는가** — "왜 하나도 안 편하지?" ↔ "조용해져도 밖은 안 사라지니까 그렇구나" ✓
- [x] **컷3의 목격이 컷2의 질문과 같은 것에 관한 것인가** — 둘 다 '소리가 멎어도 안 사라진다'는 것
- [x] **독백이 보고가 아닌가** — `~싶었다` `~생각했다` 없음
- [x] **말끝 흐리기 중독이 없는가** — 8줄 모두 완결 문장
- [x] **평어체 위주인가** — `~더라고` `~거든` `~잖아` 없음. 혼잣말(`~지?`)·알아챔(`~구나`)만 자연스럽게
- [x] 은유는 하나만 — "창밖이 계속 그 곡이었다" (여운 장 한 번)
- [x] 마지막 장은 여운 — 깨달았기 때문에 하게 된 행동(이어폰을 뺌). ep002의 '다시 해본 일'과 겹치지 않는다
- [x] 표정 4종 안에서 해결 — 생각 중 / 고민 중 / 좋아하는 순간 / 미소
- [x] 카페 브랜드명·로고 없음
