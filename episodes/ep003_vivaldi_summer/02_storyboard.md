# [ep003] 쉬는 악장인데 왜 안 쉬어지지 — 스토리 콘티

> **목소리** — 20대 여성의 말, 평어체 위주. 문장은 완결형, 독백은 보고가 아님.
> **서사** — 컷2의 질문("쉬는 부분 아니었나?")을 컷3에서 눈앞에 보고, 컷4에서 답한다.
> **비발디의 생애 정보·2악장 구조 해설 없음.** 들으면서 겪은 대로만 적는다.
> **로고·워드마크는 어떤 컷에도 넣지 않는다** — 컵·간판·앞치마 전부 무지.
> 본편 컷(2~6장)에 제목·컷 번호를 넣지 않는다.

## 이 화의 설정

```
Type:            REFLECTION (primary) / CULTURE (secondary)
Emotional Level: 1
Place:           블루보틀 — 높은 층고, 흰 타일, 원목 바 카운터, 큰 창
Time:            한여름 평일 오후 3시쯤
Dominant Sound:  그라인더와 스팀 소리, 간간이 진동벨
Central Event:   여름의 느린 악장을 듣다가, 조용한 줄 알았던 실내가 십 초도 안 쉬는 걸 알아챘다
Life Detail:     어깨에서 흘러내린 가방끈
```

---

## 1장 — 표지 (훅)
- **화면 텍스트**: "쉬는 악장인데 왜 안 쉬어지지"
- **장면**: 창가 자리에 앉은 루아 상반신. 이어폰을 낀 채 살짝 미간을 좁히고 있다 (컷1의 장면)
- **카메라**: 상반신
- **표정**: 생각 중
- **구도 메모**: 제목은 상단, 캐릭터는 우하단 — 겹치지 않게. 실사 배경 콜라주 (`03_render_prompts.md` 0번)

## 2장 — 컷1 (기 · 마음에 뭔가 걸린다)
- **장면**: 한여름 오후. 루아가 카페 안쪽 자리에 앉는다. 앉는 동작에 어깨의 가방끈이 팔꿈치까지 흘러내린다. 높은 층고, 흰 타일 벽, 큰 창으로 흰 햇빛이 들어온다
- **카메라**: 공간 와이드숏 — 실내 전체가 보이고 루아는 그 안에 있다
- **표정**: 생각 중
- **대사/텍스트**: 내레이션(상단)
  > "더워서 그냥 들어갔다.
  > 이어폰에선 비발디의 여름, 느린 악장이 나오고 있었다."
- **구도 메모**: 층고를 살려 위쪽 여백을 넓게. 카운터는 화면 안쪽 끝에 작게 보인다. **간판·컵에 글자 없음**

## 3장 — 컷2 (승 · 질문이 된다)
- **장면**: 이어폰을 낀 귀와 눈 아래까지만. 곡이 낮게 깔리다가 갑자기 커지는 순간, 눈이 살짝 움직인다
- **카메라**: 얼굴 일부 클로즈업 — 귀와 이어폰, 눈 아래까지
- **표정**: 고민 중
- **대사/텍스트**:
  - 내레이션(상단)
    > "느린 악장인데 이상하게 안 편하다.
    > 낮게 깔리다가 갑자기 확 커진다."
  - 하단 작게(**질문**) "쉬는 부분 아니었나?"
- **구도 메모**: 배경은 흐리게 밝은 면만. 이 컷에서는 실내가 아직 안 보인다

## 4장 — 컷3 (전 · 눈앞에 답이 나타난다 · **무대사**)
- **장면**: 고개를 들어 본 카운터 쪽. 그라인더가 돌고, 스팀 노즐에서 김이 올라가고, 진동벨을 받아 든 사람이 돌아서고, 문이 열린다. 네 가지가 한 화면에서 동시에 일어나고 있다
- **카메라**: 캐릭터 시점 — 루아가 보는 카운터. 화면 아래쪽에 컵을 쥔 손만 걸친다. **얼굴 안 보임**
- **표정**: (안 보임)
- **대사/텍스트**: **없음 (무대사)**
- **구도 메모**: 이 화에서 유일하게 선이 빽빽한 컷. 카운터 쪽만 해칭을 촘촘히 하고 루아 쪽 테이블은 비운다. 사람들은 얼굴 없는 실루엣

## 5장 — 컷4 (결 · 질문이 풀린다)
- **장면**: 다시 자리를 보는 루아의 옆모습. 옅은 미소. 컵을 두 손으로 감싸 쥐고 있다
- **카메라**: 허리 위, 옆모습
- **표정**: 좋아하는 순간 → 미소
- **대사/텍스트**:
  - 내레이션(상단)   ← **컷2의 질문에 대한 대답**
    > "아, 조용한 데도 원래 계속 이러는구나."
  - 하단 작게 "이 사람도 못 쉬면서 썼나 보다."
- **구도 메모**: 배경은 흰 타일과 창빛만, 여백 크게. 카운터 소리는 이제 안 그린다

## 6장 — 여운
- **장면**: 테이블 위. 휴대폰 볼륨 버튼을 누르는 손. 어깨에서 흘러내린 가방끈이 아직 팔꿈치에 걸려 있다
- **카메라**: 손 디테일 — 휴대폰과 손, 가방끈 끝
- **표정**: (인물 얼굴 없음)
- **대사/텍스트**: 상단 여백에 "볼륨을 좀 줄였다. 이제 둘 다 들린다."
- **구도 메모**: 여백 크게. 테이블 표면과 컵 아랫부분만. 새 상징물 없음

## 사색의 흐름

관념에서 시작하지 않는다. **더워서 들어간 카페에서 겪다가 알아챈다.**

| 컷 | 겪는 것 | 마음의 움직임 |
|---|---|---|
| 컷1 | 더워서 들어가 앉는다. 곡이 흐르고 있다 | 아직 아무 생각 없음 |
| 컷2 | 느린 악장이 자꾸 커졌다 작아진다 | "쉬는 부분 아니었나?" ← 질문 |
| 컷3 | 고개를 드니 카운터가 십 초도 안 쉰다 | (말 없음. 보기만 한다) |
| 컷4 | 실내 소리와 곡이 같은 짓을 하고 있다 | **"조용한 데도 원래 계속 이러는구나"** ← 알아챔 |
| 여운 | 볼륨을 줄인다 | 알아챘기 때문에 하게 된 행동 |

- **작품을 해설하지 않는다.** 2악장 구조 설명 없이 "낮게 깔리다가 갑자기 확 커진다"고 겪은 대로만
- **교훈으로 넓히지 않는다.** "쉼이란 원래 ~" 류의 문장 없음.
  마지막 추측("이 사람도 못 쉬면서 썼나 보다")은 루아 개인의 짐작으로 끝난다

## 점검

**구도**

| 컷 | 구도 | 카메라 거리 | 대사 |
|---|---|---|---|
| 컷1 | 공간 와이드숏 | 와이드 | 있음 |
| 컷2 | 얼굴 일부 | 클로즈업 | 있음 |
| 컷3 | 캐릭터 시점 | 중경 | **없음** |
| 컷4 | 옆모습 | 중경 | 있음 |
| 여운 | 손 디테일 | 디테일 | 있음 |

- 와이드숏 1컷 / 디테일숏 1컷 / 얼굴 전체가 안 보이는 컷 4컷 / 무대사 1컷
- 동일한 카메라 거리 3회 연속 없음 (중경 2연속까지)

**대사** — 글자수로 판단하지 않았다. 여덟 줄 모두 그 순간에 실제로 나올 말인지로만 봤다.

**마지막 컷** — "볼륨을 좀 줄였다. 이제 둘 다 들린다."는 **행동과 상태 보고**다.
"쉼이란 원래 조용한 게 아니다" 같은 요약 문장은 쓰지 않았다.

**경고 표현** — `결국` `어쩌면` `문득` `그제야` `우리 모두` `인생` `진정한` `소중한` `깨달았다` `본질` `나다운` `행복이란` **0건**

**금지 확인** — 금지 어미(`~한가` `~것이었다`) 0 / 억지 구어(`~더라고` `~거든` `~잖아`) 0 /
보고체(`~라고 생각했다` `~싶었다`) 0 / 말끝 흐리기 연속 0 / 은유 0 / 로고·워드마크 0
