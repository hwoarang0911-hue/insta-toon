# [ep003] 3악장에서 딴생각 — 스토리라인

## 입력 주제
> 비발디의 사계 여름에 대한 사색. 비 맞으며 카페에 들어가서 고요하게 밖을 보며 드는 생각

> **재구성 이력** — 이 화는 `brand/11_STORY_TYPES.md` 도입 후 다시 짰다.
> 원본의 핵심 사건(비를 맞고 홍대 길가 카페에 들어가 창밖을 봄, 이어폰에선 비발디의 여름)은 그대로 두고,
> **REFLECTION 구조(질문 → 목격 → 대답 → 의미 설명)를 걷어내고 CULTURE 유형으로 바꿨다.**
> 마지막 컷의 해설("비발디는 그 조용함을 이렇게 써놨다")은 삭제했다.

|---|---|

| → 실제 장소 | 홍대 길가, 큰 유리창이 있는 카페 |

| → 작은 변화나 사건 | 곡이 제일 격해지는 부분에서, 정작 시선은 창밖 사람한테 가 있다가 곡이 끝나버린다 |

**변환 결과 한 줄**
> 소나기를 맞고 들어간 홍대 카페 창가에서, 비발디 여름 3악장을 듣다가 딴생각하는 사이에 곡이 끝났다.

### 유형 선택 근거
- **왜 CULTURE인가**: 음악 앞에서 보낸 시간이 그대로 이야기가 된다. 곡에 대한 해석이나 감상평이 아니라, 곡이 흐르는 동안 실제로 무슨 일이 있었는지만 보여준다
- **왜 REFLECTION이 아닌가**: 원본이 REFLECTION이었고, 그 결과 "질문 → 목격 → 대답"의 사색 구조가 나와 마지막 컷이 곡을 해설하게 됐다. 같은 사건을 CULTURE로 놓으면 해설할 자리가 사라진다
- 직전 두 화: ep002 REFLECTION / ep001 REFLECTION → **겹치지 않게 CULTURE 선택**

## 컷 흐름

**CULTURE 흐름**: 마주함 → 몰입 → 딴생각 → 돌아옴 → 끝난 뒤

| 장 | 이 컷에서 일어나는 일 (행동) |
|---|---|
| 표지 | 창가 자리에서 젖은 머리로 이어폰을 낀 루아 (컷1의 장면) |
| 컷1 | 비를 맞고 카페로 뛰어들어와 창가에 앉는다 |
| 컷2 | 곡이 격해지는 부분에서 손이 컵 위에 멈춘다 |
| 컷3 | 시선이 창밖 사람에게 가 있다. **손가락엔 빨대 비닐이 붙어 있다** ← 생활 디테일 |
| 컷4 | 이어폰에서 다음 곡이 시작된다. 휴대폰을 확인한다 |
| 여운 | 테이블 위. 컵 옆에 떼어놓은 빨대 비닐. 창밖 비가 가늘어져 있다 |

- 마지막 컷에 독백 없음 — **삭제 테스트 대상 자체를 만들지 않았다**
