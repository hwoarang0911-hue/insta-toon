# [epNNN] 제목 — 스토리 콘티

총 6장 캐러셀. 각 장은 아래 양식으로 작성한다.
표정은 4종(생각 중/미소/좋아하는 순간/고민 중) 안에서만. 대사는 20자 이내.

> **목소리** (최우선 — `brand/01_AUTHOR_PERSONA.md`)
> 20대 여성의 혼잣말. 소리 내어 읽어 꼬이거나 40대 남성 수필가 톤이면 다시 쓴다.
> - 독백은 보고가 아니다: `~라고 생각했다` `~싶었다` `~할까 했다`로 감싸지 않는다
> - 문장은 완결형이 기본. `~해서/~있고/~인데/~니까`로 연달아 끝내지 않는다
> - 금지 어미 `~한가` `~것이었다` `~하였다` / 피할 어휘 `그새` `오래도록`

> **서사** (`brand/05_EPISODE_TEMPLATE.md`)
> 컷2에서 던진 질문을 컷3에서 눈앞에 보고, 컷4에서 답한다. 컷은 앞 컷을 받는다.

## Stage 2 체크리스트
- [ ] 표지 문장 15자 이내, 궁금증 유발
- [ ] 각 컷 = 감정 하나 + 행동 하나
- [ ] 대사 전부 20자 이내
- [ ] 텍스트 > 그림인 컷 없음
- [ ] **컷4의 대답이 컷2의 물음에 대응하는가** (두 줄을 나란히 읽어 확인)
- [ ] **컷3의 목격이 컷2의 질문과 같은 것에 관한 것인가**
- [ ] **독백이 보고가 아닌가** (`~싶었다` `~생각했다` `~할까 했다` 없는가)
- [ ] **말끝 흐리기 중독이 없는가** (`~해서/~있고/~인데/~니까` 연속 금지)
- [ ] **내레이션이 20대 여성의 말인가** (소리 내어 읽어 확인)
- [ ] 마지막 장은 여운 (직전 화와 마무리 방식이 겹치지 않는가)
- [ ] 표정 4종 안에서 해결
