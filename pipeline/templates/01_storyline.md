## 에피소드 메타데이터

```yaml
episode:
  id:                    # epNNN
  title:
  primary_type:          # OBSERVE / RELATE / STORY / TASTE / REFLECTION / CINEMA / CULTURE / DIARY / DEADPAN / SILENCE
  secondary_type:        # 없으면 비움
  emotion_level:         # 0~2 기본

moment:
  concrete_event:        # 한 문장. 눈에 보이는 사건
  central_action:        # 루아가 실제로 한 행동
  life_detail:           # 주제와 무관한 생활 디테일 1개 이상

mood:
  season:
  time:
  weather:
  temperature:
  dominant_sound:
  visual_density:        # 비움 / 보통 / 빽빽함
  pace:                  # 느림 / 보통
  texture:
  light:
```

### 유형 선택 근거

- 직전 두 화의 주 유형: ep(N-1) ○○○ / ep(N-2) ○○○ → **겹치지 않음 확인**
- REFLECTION을 고른 경우, OBSERVE·RELATE·STORY·TASTE로 안 되는 이유:

## 컷 흐름

유형별 흐름은 `brand/11_STORY_TYPES.md` 11장을 따른다.
**기승전결은 STORY·REFLECTION에만 해당한다.**

| 장 | 이 컷에서 일어나는 일 (행동으로 쓴다) |
|---|---|
| 표지 | (본편의 대표 장면 하나 — 새 장면을 만들지 않는다) |
| 컷1 | |
| 컷2 | |
| 컷3 | |
| 컷4 | |
| 여운 | (끝난 자리. 교훈 금지) |

- 각 칸은 **보이는 행동**으로 쓴다. "~을 깨닫는다"(✗) → "~을 집어 든다"(○)
- 생활 디테일이 어느 컷에 들어가는지 표시한다

## Stage 1 체크리스트
- [ ] **추상 주제를 구체적 순간으로 변환했는가** — 장소·시간·행동이 다 들어있는가
- [ ] 중심 사건이 **한 문장으로 쓸 수 있고 눈에 보이는가**
- [ ] 중심 사건이 하나인가
- [ ] 주 유형을 골랐는가 (보조 포함 2개 이하)
- [ ] **감성적 소재라는 이유로 REFLECTION을 자동 선택하지 않았는가**
- [ ] 직전 두 화와 주 유형이 겹치지 않는가
- [ ] 감정 레벨이 0~2인가
- [ ] MOOD 9개 항목을 다 채웠는가
- [ ] **주제와 무관한 생활 디테일을 골랐는가**
- [ ] 컷 흐름을 행동으로 썼는가 (깨달음·감정이 아니라)
- [ ] 루아의 세계에서 일어날 수 있는 일인가
- [ ] 훈계·지식 자랑이 아닌가
- [ ] 복선·다른 화와의 연계를 설계하지 않았는가
