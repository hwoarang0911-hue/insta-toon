# 자연스러움 검수 체크리스트

> Stage 2(콘티)를 마친 뒤 **반드시 통과해야** Stage 3(렌더링 지시서)으로 넘어간다.
> 기준은 `brand/11_STORY_TYPES.md`다.

## A. 검수 질문 10

각 항목에 정직하게 답한다. **괄호 안이 통과 조건이다.**

1. 이 에피소드는 **실제 사건에서 시작하는가?** (예)
2. **첫 컷에서 주제를 직접 말하는가?** (아니오)
3. **캐릭터가 작가의 메시지를 대신 말하는가?** (아니오)
4. **주제와 직접 무관한 생활 디테일이 있는가?** (예 — 최소 1개)
5. **대사 없이도 컷 흐름이 이해되는가?** (예)
6. 모든 컷의 구도가 비슷하지 않은가? (예 — 다르다)
7. **감정 레벨이 0~2 범위인가?** (예)
8. **마지막 컷이 의미를 설명하는가?** (아니오)
9. **마지막 독백을 삭제할 수 있는가?** (예 → 삭제한다 / 아니오 → 행동·사물·구도를 고친다)
10. 실제 사람이 할 법한 행동과 말인가? (예)

## B. 재작성 조건 — 하나라도 걸리면 스크립트를 다시 쓴다

- [ ] 완결된 감성 문장이 **3개 이상**
- [ ] 마지막 컷에 **교훈**
- [ ] **중심 사건 2개 이상**
- [ ] **생활 디테일 없음**
- [ ] **무대사 컷 없음**
- [ ] **동일한 구도 3회 이상**
- [ ] **감정 레벨 4 이상**
- [ ] 캐릭터가 **"우리" · "인생" · "결국"** 으로 내용을 정리함

> 재작성은 문장을 다듬는 게 아니다. **사건과 행동을 다시 고르는 것이다.**
> 같은 구조에서 어휘만 바꾸면 같은 결과가 나온다.

## C. 경고 표현 스캔

아래 표현이 스크립트에 있으면 한 번 더 본다. 남길 이유가 없으면 지운다.

```
결국   어쩌면   문득   그제야   우리 모두
인생   진정한   소중한   깨달았다   본질   나다운   행복이란
```

기계 스캔:

```bash
grep -nE "결국|어쩌면|문득|그제야|우리 모두|인생|진정한|소중한|깨달았다|본질|나다운|행복이란" \
  episodes/epNNN_*/02_storyboard.md
```

## D. 구도 점검 (5컷 기준)

- [ ] 와이드숏 1컷 이상
- [ ] 사물 또는 손 디테일숏 1컷 이상
- [ ] 캐릭터 얼굴 전체가 보이지 않는 컷 1컷 이상
- [ ] 무대사 컷 1컷 이상
- [ ] 동일한 카메라 거리가 3회 이상 연속되지 않음

## E. 유형 로테이션 점검

- [ ] 주 유형이 **직전 두 화와 겹치지 않는가**
- [ ] 감성적 소재를 이유로 REFLECTION을 **자동 선택하지 않았는가**
- [ ] 보조 유형까지 합쳐 **2개 이하인가**

## F. 문서 간 정합성

- [ ] 콘티의 「이미지에 들어가는 글자」 표와 `03_render_prompts.md`의 따옴표 문구가 **글자 하나까지 일치**
- [ ] 본편 컷에 **에피소드 제목·컷 번호·다른 컷의 문구**가 들어가지 않았는가
- [ ] 캡션이 본편 문장을 복사하지 않았는가
