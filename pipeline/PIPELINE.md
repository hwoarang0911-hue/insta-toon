# Restnote 에피소드 제작 파이프라인

주제 한 줄을 입력받아 아래 4단계를 순서대로 실행한다.
각 단계의 산출물은 `pipeline/templates/`의 양식을 따르고, 단계별 체크리스트를 통과해야 다음 단계로 넘어간다.

```
주제 입력
   │
   ▼
Stage 1  스토리라인   → episodes/epNNN_slug/01_storyline.md
   │  (핵심 메시지 1개, 감정 곡선)
   ▼
Stage 2  스토리 콘티  → episodes/epNNN_slug/02_storyboard.md
   │  (6장: 표지 + 4컷 + 여운)
   ▼
Stage 3  렌더링 지시서 → episodes/epNNN_slug/03_render_prompts.md
   │  (컷별 나노바나나 + GPT 듀얼 프롬프트)
   ▼
Stage 4  캡션·해시태그 → episodes/epNNN_slug/04_caption.md
```

## 사전 준비
- `brand/` 전체 문서를 읽고 시작한다. 특히 02(캐릭터), 05(에피소드 구조), 08(비주얼 랭귀지)은 필수.
- 에피소드 번호: `episodes/` 내 기존 최대 번호 + 1
- 폴더명: `epNNN_영문슬러그` (예: `ep002_first_fallen_leaf`)

## Stage 1 — 스토리라인
먼저 `brand/10_MOOD_BANK.md`(원천 심상 아카이브)를 훑는다. 주제와 공명하는 심상이 있으면 반영하고,
뻔한 계절 소재는 아카이브의 방식대로 한 겹 더 들어간 결로 바꿔 제안한다.
그다음 주제를 받아 다음을 결정한다:
1. 콘텐츠 트랙 (A 클래식 / B 자연·계절 / C 조용한 일상 — `brand/04_WORLDVIEW.md`)
2. **핵심 메시지 1개** (두 개면 에피소드를 나눈다)
3. 독자가 얻어갈 한 문장
4. **질문과 대답을 먼저 정한다** — ① 컷2에서 루아가 던질 물음 한 줄 → ② 그 물음의 답이 되는 컷4 한 줄 → ③ 답을 눈앞에 보여줄 컷3의 장면. 이 셋이 안 맞으면 스토리라인이 아직 없는 것이다
5. 기승전결 흐름 (걸린다 → 묻는다 → 눈앞에서 본다 → 답한다 → 그래서 머문다)

**체크리스트**
- [ ] 메시지가 하나인가
- [ ] **컷2의 질문과 컷4의 대답을 먼저 정했는가** — 둘을 나란히 읽어 묻고 답한 것처럼 읽히는가
- [ ] **컷3의 목격이 그 질문과 같은 것에 관한 장면인가**
- [ ] **주제 설명이 아니라 루아의 사색이 중심인가** — 스토리라인의 뼈대가 '정보의 흐름'이 아니라 '마음이 정리되어가는 흐름'인가
- [ ] 루아의 세계(일상적, 조용함)에서 일어날 수 있는 이야기인가
- [ ] 훈계·지식 자랑이 아닌가
- [ ] 여운으로 끝날 수 있는 이야기인가
- [ ] 복선·떡밥·다른 화와의 연계를 설계하지 않았는가 (이 화 하나로 완결된 사색인가)

## Stage 2 — 스토리 콘티
스토리라인을 6장으로 분해한다 (`brand/05_EPISODE_TEMPLATE.md` 구조).
각 장마다: 장면 묘사 / 카메라 / 루아 표정(4종 중 택1) / 대사·텍스트 / 구도 메모

**체크리스트**
- [ ] 표지 문장이 한 호흡에 읽히고 궁금증을 만드는가
- [ ] 각 컷이 감정 하나·행동 하나인가
- [ ] 대사가 자연스럽게 읽히는가 (글자 수가 아니라 말의 흐름으로 판단)
- [ ] 텍스트가 그림보다 많은 컷은 없는가
- [ ] **컷4의 깨달음이 컷2의 질문에 대답하는가** — 두 줄을 나란히 읽어 묻고 답한 것처럼 읽히지 않으면 다시 짠다
- [ ] **컷3의 목격이 컷2의 질문과 같은 것에 관한 것인가** — 아무 장면이나 우연히 보는 게 아니다
- [ ] **독백이 보고가 아닌가** — `~라고 생각했다` `~싶었다` `~할까 했다`로 생각을 감싸지 않았는가
- [ ] 컷2~4가 독백 기법(자문자답·생각의 심화 등)으로 발전하는가
- [ ] 깨달음이 회상·논리가 아니라 눈앞의 우연한 목격에서 오는가
- [ ] **내레이션이 20대 여성의 말인가** — 소리 내어 읽어 40대 남성 수필가 톤이면 전부 다시 쓴다. 금지 어미(`~한가`, `~것이었다`, `~하였다`)·올드한 어휘(`그새`, `오래도록`)가 없는가
- [ ] **평어체 위주인가** — `~더라고` `~거든` `~잖아`로 억지 친근함을 만들지 않았는가
- [ ] **말하는 것처럼 들리는가** — 소리 내어 읽어 한 번에 안 읽히거나 실제로 이렇게 말할 사람이 없으면 그 문장은 다시 쓴다. AI스러운 정형 문구(기계적 대구, 반복되는 질문형 마무리)도 함께 점검
- [ ] 마지막 장이 결론이 아닌 여운인가 (마무리 방식이 직전 화와 겹치지 않는가)
- [ ] 표정이 모두 4종 안에서 해결되는가

## Stage 3 — 렌더링 지시서
콘티의 각 장을 이미지 생성 프롬프트로 변환한다 (`pipeline/templates/03_render_prompts.md` 양식).
- 컷마다 **나노바나나(Gemini)용 한국어 지시문**과 **GPT용 영어 프롬프트** 두 벌 작성
- 참조 이미지 첨부 지시 포함 (`brand/06_IMAGE_RULE.md`)
- 스타일 고정 문구와 금지 문구(negative)를 매 컷에 삽입

**체크리스트**
- [ ] 모든 컷에 character_sheet.png 첨부 지시가 있는가
- [ ] 2번째 컷부터 직전 컷 첨부 지시가 있는가
- [ ] 스타일 고정 문구(만년필 스케치, 흑백, 여백)가 있는가
- [ ] 텍스트 렌더링 지시(정확한 문구 명시)가 있는가

## Stage 4 — 캡션·해시태그
`pipeline/templates/04_caption.md` 양식으로 인스타 게시용 캡션 작성.

**캡션은 툰의 요약이 아니라 툰이 끝난 뒤 이어진 생각이다.**
독자는 6장을 다 넘긴 다음 캡션을 읽는다. 같은 말이 또 나오면 읽을 이유가 없다.
본편이 끝난 지점에서 사색을 **한 겹 더** 진행시킨다 (깨달음을 자기 삶에 대보기, 그 뒤에 있었던 일, 솔직한 마음).

- 에세이 3~4문장 (작가 페르소나 톤 — 평어체 위주)
- **본편 문장을 복사해 오지 않는다**
- **곡 추천은 넣지 않는다.** 곡은 본문에서 사색의 계기로만 다루고, 캡션에서 큐레이션하지 않는다
- 해시태그는 `brand/09_GROWTH_STRATEGY.md`의 고정 세트 사용

## 완료 보고
4개 파일 생성 후 사용자에게 요약 보고:
- 에피소드 제목과 핵심 메시지
- 6장 구성 한 줄 요약
- 다음 액션 (이미지 생성 도구에 프롬프트 투입)
