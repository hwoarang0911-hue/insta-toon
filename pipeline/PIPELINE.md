# Restnote 에피소드 제작 파이프라인

주제 한 줄을 입력받아 아래 4단계를 순서대로 실행한다.
각 단계의 산출물은 `pipeline/templates/`의 양식을 따르고, 단계별 체크리스트를 통과해야 다음으로 넘어간다.

```
주제 입력
   │
   ▼
Stage 1  스토리라인   → episodes/epNNN_slug/01_storyline.md
   │  (구체적 순간 변환 · 유형 · 감정 레벨 · MOOD · 중심 사건)
   ▼
Stage 2  스토리 콘티  → episodes/epNNN_slug/02_storyboard.md
   │  (행동 먼저 → 대사 나중 → 구도 → 검수)
   ▼
Stage 3  렌더링 지시서 → episodes/epNNN_slug/03_render_prompts.md
   │  (표지 별도 + 본편 5장 통합 프롬프트 + 컷별 상세)
   ▼
Stage 4  캡션·해시태그 → episodes/epNNN_slug/04_caption.md
```

## 사전 준비
- `brand/` 문서를 읽고 시작한다. **필수: 02(캐릭터) · 11(이야기 유형) · 05(에피소드 구조) · 08(비주얼)**
- 에피소드 번호: `episodes/` 내 기존 최대 번호 + 1
- 폴더명: `epNNN_영문슬러그`

# 에피소드 생성 파이프라인 (STEP 1~9)

**순서는 `brand/11_STORY_TYPES.md` 6장이 기준이다.** Stage 1~2에서 아래 STEP을 그대로 밟는다.

| STEP | 단계 | 어디에 기록 |
|---|---|---|
| 1 | 스토리 유형 선택 | 01 `Type` |
| 2 | **추상 주제를 구체적 순간으로 변환** | 01 `Core Moment` |
| 3 | MOOD 설정 | 01 `Metadata` (9항목) |
| 4 | 중심 사건 하나 선택 | 01 `Central Event` |
| 5 | 생활 디테일 추가 | 01 `Life Detail` |
| 6 | **대사 없이 컷 구성** | 02 각 컷 `Visible Action` |
| 7 | 필요한 대사만 추가 | 02 각 컷 `Dialogue` |
| 8 | **마지막 해설 삭제** | 02 CLOSING |
| 9 | 자연스러움 검수 | `brand/11_STORY_TYPES.md` 11장 |

**6번과 7번의 순서를 바꾸지 않는다.** 대사를 먼저 쓰면 그림이 대사의 삽화가 된다.
**감정 레벨은 스크립트 작성 전에 정한다** (동 문서 4장). 유형마다 권장 범위가 다르다.

이 저장소는 위 9단계 뒤에 두 단계를 더 둔다:

| | 단계 | 산출물 |
|---|---|---|
| Stage 3 | 이미지 생성 프롬프트 작성 | 03 |
| Stage 4 | 캡션·해시태그 | 04 |

## 유형 선택 우선순위

사용자가 유형을 지정하지 않으면:

```
OBSERVE → RELATE → STORY → TASTE → REFLECTION
```

**감성적이거나 철학적인 소재라고 해서 자동으로 REFLECTION을 선택하지 않는다.**
유형 선택이 애매하면 **설명이 가장 적게 필요한 유형**을 우선한다 (동 문서 14장).

**연재 운영 원칙** (동 문서 19장)
- 동일 유형을 3회 이상 연속 사용하지 않는다
- 사색형을 연속 게시하지 않는다
- 문화 감상형 다음에는 **관찰형 또는 공감형**을 배치한다
- 무대사형은 전체 연재의 10% 이내
- 유머형 다음에는 분위기가 다른 유형을 배치한다
- 20화 기준 권장 비율은 동 문서 12장

**유형 조합** (동 문서 18장) — 주 유형 1개 + 보조 1개까지.
지양 조합: REFLECTION+REFLECTION / CULTURE+정보 설명 / DEADPAN+과장 개그 / CINEMA+긴 독백 / SILENCE+상징 과잉

## Stage 1 — 스토리라인

`brand/10_MOOD_BANK.md`(원천 심상 아카이브)를 훑어 주제와 공명하는 심상이 있으면 반영한다.
뻔한 계절 소재는 아카이브의 방식대로 한 겹 더 들어간 결로 바꾼다.

그다음 **13단계의 1~7번**을 순서대로 수행해 `pipeline/templates/01_storyline.md` 양식을 채운다.

**체크리스트**
- [ ] **추상 주제를 구체적 순간으로 변환했는가** — 장소·시간·행동이 다 들어있는가
- [ ] 중심 사건이 **한 문장으로 쓸 수 있고 눈에 보이는가**
- [ ] 중심 사건이 하나인가
- [ ] 주 유형을 골랐는가 (보조 포함 2개 이하)
- [ ] **감성적 소재라는 이유로 REFLECTION을 자동 선택하지 않았는가**
- [ ] 직전 두 화와 주 유형이 겹치지 않는가
- [ ] 감정 레벨이 0~2인가
- [ ] MOOD 9개 항목을 다 채웠는가
- [ ] **주제와 무관한 생활 디테일을 골랐는가**
- [ ] 루아의 세계에서 일어날 수 있는 일인가
- [ ] 훈계·지식 자랑이 아닌가
- [ ] 복선·다른 화와의 연계를 설계하지 않았는가

## Stage 2 — 스토리 콘티

스토리라인을 6장으로 분해한다 (`brand/05_EPISODE_TEMPLATE.md`).
**13단계의 8~12번**을 순서대로 수행한다.

각 컷은 `visible_action` → `character_reaction` → `composition` → `camera_distance` →
`background_detail` → `continuity_from_previous` 를 먼저 채우고, **`dialogue`는 마지막에** 채운다.

**콘티의 대사가 곧 이미지에 그려지는 글자다.** 마지막에 「이미지에 들어가는 글자」 표를 채워 Stage 3의 기준으로 넘긴다.

**체크리스트**
- [ ] **모든 컷의 `visible_action`을 대사보다 먼저 썼는가**
- [ ] **대사 없이도 컷 흐름이 이해되는가**
- [ ] 무대사 컷이 최소 하나 있는가
- [ ] 완결된 감성 문장이 3개 미만인가
- [ ] 그림으로 보이는 것을 대사로 반복하지 않았는가
- [ ] 경고 표현(`결국` `어쩌면` `문득` `그제야` `인생` `진정한` `소중한` `깨달았다` 등)을 스캔했는가
- [ ] 와이드숏·디테일숏·얼굴 안 보이는 컷이 각각 하나 이상인가
- [ ] 동일한 카메라 거리가 3회 이상 연속되지 않는가
- [ ] 컷마다 `continuity_from_previous`가 채워졌는가
- [ ] **마지막 컷 삭제 테스트를 수행했는가** — 독백을 지워도 유지되면 지웠는가
- [ ] 마지막 컷이 교훈·요약·철학적 질문이 아닌가
- [ ] 본편 컷에 제목·컷 번호·다른 컷 문구가 없는가
- [ ] 표정이 4종 안에서 해결되는가
- [ ] **`pipeline/NATURALNESS_CHECKLIST.md`를 끝까지 통과했는가**

## Stage 3 — 렌더링 지시서

콘티의 각 장을 이미지 생성 프롬프트로 변환한다 (`pipeline/templates/03_render_prompts.md` 양식).

- **표지(1장)는 예외**: 실사 배경 사진 + 캐릭터 컷아웃 합성 워크플로를 0번에 따로 작성
- **그 아래 「한 번에 전달하기」 통합 프롬프트** (한국어판·영어판) — 본편 5장(컷1~4+여운) 대상
- 그 아래 컷별 상세 프롬프트: 나노바나나(Gemini)용 한국어 / GPT용 영어
- **프롬프트 작성 우선순위를 지킨다** (`brand/06_IMAGE_RULE.md`) — 물리적 장면이 분위기보다 먼저

**체크리스트**
- [ ] **각 컷 프롬프트가 콘티의 `visible_action`에서 시작하는가** (분위기 형용사로 시작하지 않는가)
- [ ] 카메라 구도·거리가 콘티와 일치하는가
- [ ] 생활 디테일이 프롬프트에 들어갔는가
- [ ] **"한 장면만" 문구가 모든 컷에 있는가** (격자·콜라주·다른 컷 문구 금지)
- [ ] 표지는 0번 콜라주 워크플로로 별도 작성됐는가
- [ ] 본편 프롬프트에 에피소드 제목이 들어가지 않았는가
- [ ] 모든 컷에 character_sheet.png 첨부 지시가 있는가
- [ ] 컷2(3장)부터 직전 컷 첨부 지시가 있는가
- [ ] 스타일 고정 문구(만년필, 두꺼운 선, 흰 배경, 4:5, 컷 외곽선)가 있는가
- [ ] **프롬프트 안 한글 문구가 콘티의 「이미지에 들어가는 글자」 표와 글자 하나까지 일치하는가**
- [ ] 감정 형용사 반복·불필요한 상징물이 없는가
- [ ] 로고·브랜드명 노출 금지 지시가 있는가
- [ ] 통합 프롬프트가 자립적인가 (저장소를 모르는 사람이 복사해 가도 쓸 수 있는가)

## Stage 4 — 캡션·해시태그

`pipeline/templates/04_caption.md` 양식으로 인스타 게시용 캡션 작성.

**캡션은 툰의 요약이 아니라 툰이 끝난 뒤 이어진 생각이다.**
독자는 6장을 다 넘긴 다음 캡션을 읽는다. 같은 말이 또 나오면 읽을 이유가 없다.

- 에세이 3~4문장 (평어체 위주)
- **본편 문장을 복사해 오지 않는다**
- **곡 추천은 넣지 않는다**
- **캡션에서 본편의 의미를 설명하지 않는다** — 본편이 안 한 일을 캡션이 대신 하면 안 된다
- 해시태그는 `brand/09_GROWTH_STRATEGY.md`의 고정 세트 사용
