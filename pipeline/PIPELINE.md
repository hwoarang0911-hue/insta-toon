# Restnote 에피소드 제작 파이프라인

주제 한 줄을 입력받아 아래 4단계를 순서대로 실행한다.
각 단계의 산출물은 `pipeline/templates/`의 양식을 따르고, 단계별 체크리스트를 통과해야 다음 단계로 넘어간다.

```
주제 입력
   │
   ▼
Stage 1  스토리라인   → episodes/epNNN_slug/01_storyline.md
   │  (핵심 메시지 1개, 감정 곡선)
   ▼
Stage 2  스토리 콘티  → episodes/epNNN_slug/02_storyboard.md
   │  (6장: 표지 + 4컷 + 여운)
   ▼
Stage 3  렌더링 지시서 → episodes/epNNN_slug/03_render_prompts.md
   │  (컷별 나노바나나 + GPT 듀얼 프롬프트)
   ▼
Stage 4  캡션·해시태그 → episodes/epNNN_slug/04_caption.md
```

## 사전 준비
- `brand/` 전체 문서를 읽고 시작한다. 특히 02(캐릭터), 05(에피소드 구조), 08(비주얼 랭귀지)은 필수.
- 에피소드 번호: `episodes/` 내 기존 최대 번호 + 1
- 폴더명: `epNNN_영문슬러그` (예: `ep002_first_fallen_leaf`)

## Stage 1 — 스토리라인
먼저 `brand/10_MOOD_BANK.md`(원천 심상 아카이브)를 훑는다. 주제와 공명하는 심상이 있으면 반영하고,
뻔한 계절 소재는 아카이브의 방식대로 한 겹 더 들어간 결로 바꿔 제안한다.
그다음 주제를 받아 다음을 결정한다:
1. 콘텐츠 트랙 (A 클래식 / B 자연·계절 / C 조용한 일상 — `brand/04_WORLDVIEW.md`)
2. **핵심 메시지 1개** (두 개면 에피소드를 나눈다)
3. 독자가 얻어갈 한 문장
4. 감정 곡선 위의 이야기 흐름 (호기심→공감→침잠→울림→머무름)
5. (트랙 A일 때) 추천할 곡 1곡

**체크리스트**
- [ ] 메시지가 하나인가
- [ ] 루아의 세계(일상적, 조용함)에서 일어날 수 있는 이야기인가
- [ ] 훈계·지식 자랑이 아닌가
- [ ] 여운으로 끝날 수 있는 이야기인가

## Stage 2 — 스토리 콘티
스토리라인을 6장으로 분해한다 (`brand/05_EPISODE_TEMPLATE.md` 구조).
각 장마다: 장면 묘사 / 카메라 / 루아 표정(4종 중 택1) / 대사·텍스트 / 구도 메모

**체크리스트**
- [ ] 표지 문장이 15자 이내이고 궁금증을 만드는가
- [ ] 각 컷이 감정 하나·행동 하나인가
- [ ] 대사가 모두 20자 이내인가
- [ ] 텍스트가 그림보다 많은 컷은 없는가
- [ ] 마지막 장이 결론이 아닌 여운인가
- [ ] 표정이 모두 4종 안에서 해결되는가

## Stage 3 — 렌더링 지시서
콘티의 각 장을 이미지 생성 프롬프트로 변환한다 (`pipeline/templates/03_render_prompts.md` 양식).
- 컷마다 **나노바나나(Gemini)용 한국어 지시문**과 **GPT용 영어 프롬프트** 두 벌 작성
- 참조 이미지 첨부 지시 포함 (`brand/06_IMAGE_RULE.md`)
- 스타일 고정 문구와 금지 문구(negative)를 매 컷에 삽입

**체크리스트**
- [ ] 모든 컷에 character_sheet.png 첨부 지시가 있는가
- [ ] 2번째 컷부터 직전 컷 첨부 지시가 있는가
- [ ] 스타일 고정 문구(만년필 스케치, 흑백, 여백)가 있는가
- [ ] 텍스트 렌더링 지시(정확한 문구 명시)가 있는가

## Stage 4 — 캡션·해시태그
`pipeline/templates/04_caption.md` 양식으로 인스타 게시용 캡션 작성.
- 짧은 에세이 2~3문장 (작가 페르소나 톤)
- 트랙 A면 오늘의 곡 추천
- 해시태그는 `brand/09_GROWTH_STRATEGY.md`의 고정 세트 사용

## 완료 보고
4개 파일 생성 후 사용자에게 요약 보고:
- 에피소드 제목과 핵심 메시지
- 6장 구성 한 줄 요약
- 다음 액션 (이미지 생성 도구에 프롬프트 투입)
