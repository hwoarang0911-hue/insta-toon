# Restnote (레스트노트)

클래식 음악과 자연에 대한 사색을 조용히 기록하는 감성 인스타툰.
주인공 **루아**(20대 여성)가 일상의 쉼표 같은 순간들을 담백하게 담아낸다.

> **Restnote = Rest(쉼표) + Note(기록)** — 음악에서 쉼표는 소리가 없는 순간이지만, 음악의 일부다.

## 사용법

이 저장소에서 Claude에게 **주제 한 줄**을 던지면 에피소드가 자동 생성된다.

```
예: "가을 첫 낙엽과 쇼팽 녹턴"
예: "비 오는 날 버스에서 들은 바흐"
예: "말없이 걷기 좋은 계절"
```

Claude는 `CLAUDE.md`의 규칙에 따라 4단계 파이프라인을 실행한다:

| 단계 | 산출물 | 내용 |
|---|---|---|
| 1 | `01_storyline.md` | 핵심 메시지 1개, 기승전결 (컷2의 질문 → 컷4의 대답) |
| 2 | `02_storyboard.md` | 6장 캐러셀 콘티 — **여기 대사가 이미지에 그려지는 글자다** |
| 3 | `03_render_prompts.md` | 컷별 이미지 생성 프롬프트 (나노바나나 + GPT) |
| 4 | `04_caption.md` | 인스타 게시글 캡션 — 툰의 요약이 아니라 **툰이 끝난 뒤 이어지는 사색** |

## 이미지 만들기

표지(1장)와 나머지(컷1~4+여운, 2~6장)는 만드는 방식이 다르다.

**표지 — 실사 배경 콜라주** (`03_render_prompts.md`의 0번)
1. 에피소드 장소의 실제 사진을 준비한다
2. 캐릭터 컷아웃 프롬프트로 배경 없는 루아만 생성
3. 사진 편집 툴에서 사진 위에 합성하고, 표지 문구는 손글씨 폰트로 얹는다

**컷1~4·여운 — 「🚀 한 번에 전달하기」 통합 프롬프트**
1. 이미지 생성 AI(ChatGPT / Gemini·나노바나나)에 `assets/character_sheet.png`를 첨부
2. 통합 프롬프트를 통째로 복사해 붙여넣기 — 한국어판(Gemini용)과 영어판(ChatGPT용)이 준비돼 있다
3. 컷1이 나오면 그 이미지를 첨부하고 "다음 장" → 여운까지 반복

만든 이미지는 `episodes/epNNN_*/images/` 에 `01_cover.png` ~ `06_outro.png`로 보관하면 나중에 찾기 쉽다.
(인스타에 올리는 것만이 목적이면 저장소에 안 올려도 된다.)

통합 프롬프트는 **링크 없이 그것만으로 완결**된다 (캐릭터 스펙·그림체·금지 사항·5컷 지시 포함).
링크로 전달하고 싶으면 같은 파일의 (C) 항목을 참고한다. 특정 컷만 다시 뽑고 싶으면 아래쪽 컷별 상세 프롬프트를 쓴다.

## 저장소 구조

```
brand/       브랜드 바이블 (정체성, 캐릭터, 그림체, 세계관, 성장 전략)
assets/      캐릭터 시트, 프로필, 기준 샘플 이미지
pipeline/    파이프라인 정의와 단계별 템플릿
episodes/    생성된 에피소드 (ep001은 형식·톤의 레퍼런스)
CLAUDE.md    파이프라인 오케스트레이션 규칙
```

## 핵심 원칙

- 한 화에는 하나의 메시지만
- 텍스트가 그림보다 많아지지 않는다
- 마지막 장은 항상 여운으로 끝낸다
