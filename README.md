# Restnote (레스트노트)

클래식 음악과 자연이 스치는 일상에서, 체험하며 발견한 사색을 기록하는 인스타툰.
주인공 **루아**(20대 여성)가 지나갈 뻔한 순간에 잠깐 멈춰 선다.

> **Restnote = Rest(쉼표) + Note(기록)** — 음악에서 쉼표는 소리가 없는 순간이지만, 음악의 일부다.

## 프로젝트의 방향

> **이 프로젝트는 일상에서 체험하며 발견하는 사색을 기록하는 인스타툰이다.**

알맹이는 **루아가 그 자리에서 알아챈 것**이다. 관찰만 하고 끝나지도, 교훈을 가르치지도 않는다.

- **체험이 먼저, 사색이 그 다음** — 관념에서 출발해 장면을 끼워 맞추지 않는다
- **알아챈 것은 남긴다** — "아, 물은 원래 계속 다른 거구나" 같은 작은 알아챔이 목적지다
- 다만 그 알아챔을 **보편적 교훈으로 확장하지 않는다** ("우리 인생도", "결국 중요한 건")
- 루아는 작가의 메시지를 대신 말하지 않는다
- 모든 대사를 명언처럼 만들지 않는다. 대사가 없어도 되는 컷은 비운다
- 매 화 같은 틀로 나오지 않게 **이야기 유형을 돌린다** (`brand/11_STORY_TYPES.md`)

> ⚠️ **규칙을 지키려고 이야기를 깎지 않는다.**
> 무대사 컷·구도 배분은 점검 도구이지 통과 게이트가 아니다.
> **대사는 글자수로 판단하지 않는다.**

## 에피소드 생성 시 읽는 문서 (순서대로)

```
1. README.md                       ← 지금 이 문서. 방향
2. CLAUDE.md                       오케스트레이션 규칙과 절대 규칙
3. brand/11_STORY_TYPES.md         이야기 유형·감정 레벨·중심 사건·대사량·마지막 컷·구도
4. brand/02_CHARACTER.md           캐릭터 외형 (변경 금지 스펙)
5. brand/05_EPISODE_TEMPLATE.md    6장 구조, 표지와 본편의 분리
6. pipeline/PIPELINE.md            13단계 생성 순서
7. pipeline/templates/*.md         각 Stage 양식
8. episodes/epNNN_*/02_storyboard.md   해당 에피소드 스크립트
9. episodes/epNNN_*/03_render_prompts.md  해당 컷 프롬프트
```

이미지 생성 시에는 **`brand/02_CHARACTER.md`(외형) + `brand/11_STORY_TYPES.md`(장면) + 해당 에피소드 콘티 + 해당 컷 프롬프트**를 함께 읽는다.

## 사용법

이 저장소에서 Claude에게 **주제 한 줄**을 던지면 에피소드가 자동 생성된다.

```
예: "가을 첫 낙엽과 쇼팽 녹턴"
예: "비 오는 날 버스에서 들은 바흐"
예: "말없이 걷기 좋은 계절"
```

Claude는 `pipeline/PIPELINE.md`의 13단계를 거쳐 4개 파일을 만든다:

| 단계 | 산출물 | 내용 |
|---|---|---|
| 1 | `01_storyline.md` | 구체적 순간 변환 · 유형 · 감정 레벨 · MOOD · 중심 사건 · 생활 디테일 |
| 2 | `02_storyboard.md` | 6장 콘티 — **행동 먼저, 대사 나중.** 여기 대사가 이미지에 그려지는 글자다 |
| 3 | `03_render_prompts.md` | 컷별 이미지 생성 프롬프트 (나노바나나 + GPT) |
| 4 | `04_caption.md` | 인스타 게시글 캡션 — 툰의 요약이 아니라 **툰이 끝난 뒤 이어지는 생각** |

Stage 2를 마치면 `pipeline/NATURALNESS_CHECKLIST.md`로 한 번 훑는다 (게이트가 아니라 점검 도구).

## 이미지 만들기

표지(1장)와 본편(컷1~4+여운, 2~6장)은 만드는 방식이 다르다.

**표지 — 실사 배경 콜라주** (`03_render_prompts.md`의 0번)
1. 에피소드 장소의 실제 사진을 준비한다
2. 캐릭터 컷아웃 프롬프트로 배경 없는 루아만 생성
3. 사진 위에 합성하고, 제목을 손글씨 폰트로 얹는다 (원근·빛을 맞추고, 제목과 캐릭터가 겹치지 않게)

**본편 — 「🚀 한 번에 전달하기」 통합 프롬프트**
1. 이미지 생성 AI(ChatGPT / Gemini·나노바나나)에 `assets/character_sheet.png`를 첨부
2. 통합 프롬프트를 통째로 복사해 붙여넣기 — 한국어판(Gemini용)과 영어판(ChatGPT용)이 준비돼 있다
3. 컷1이 나오면 그 이미지를 첨부하고 "다음 장" → 여운까지 반복

**본편 컷에는 에피소드 제목을 넣지 않는다.** 제목은 표지에만 한 번.

만든 이미지는 `episodes/epNNN_*/images/` 에 `01_cover.png` ~ `06_outro.png`로 보관한다.

## 저장소 구조

```
brand/       브랜드 바이블
  00_MASTER            프로젝트 정의 + 문서 기준표
  01_AUTHOR_PERSONA    말투와 문체 (목소리)
  02_CHARACTER         캐릭터 외형 (변경 금지)
  03_DRAWING_STYLE     그림체
  04_WORLDVIEW         세계관 · 3트랙
  05_EPISODE_TEMPLATE  6장 구조 · 표지/본편 분리
  06_IMAGE_RULE        이미지 생성 규칙 · 프롬프트 우선순위
  07_FORBIDDEN         금지 목록
  08_VISUAL_LANGUAGE   구도 라이브러리
  09_GROWTH_STRATEGY   운영 전략
  10_MOOD_BANK         원천 심상 아카이브
  11_STORY_TYPES       ★ 이야기 유형과 자연스러움 (이야기의 기준)
assets/      캐릭터 시트, 프로필, 기준 샘플 이미지
pipeline/    파이프라인 정의 · 자연스러움 체크리스트 · 단계별 템플릿
episodes/    생성된 에피소드
CLAUDE.md    오케스트레이션 규칙
```

## 핵심 원칙

- 한 화에 일어나는 일은 하나
- 텍스트가 그림보다 많아지지 않는다
- 마지막 장에서 의미를 설명하지 않는다
- 감정 레벨 0~2 — 작은 사건에 큰 감정을 붙이지 않는다
