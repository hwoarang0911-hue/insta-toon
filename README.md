# Restnote (레스트노트)

클래식 음악과 자연에 대한 사색을 조용히 기록하는 감성 인스타툰.
주인공 **루아**(20대 여성)가 일상의 쉼표 같은 순간들을 담백하게 담아낸다.

> **Restnote = Rest(쉼표) + Note(기록)** — 음악에서 쉼표는 소리가 없는 순간이지만, 음악의 일부다.

## 사용법

이 저장소에서 Claude에게 **주제 한 줄**을 던지면 에피소드가 자동 생성된다.

```
예: "가을 첫 낙엽과 쇼팽 녹턴"
예: "비 오는 날 버스에서 들은 바흐"
예: "말없이 걷기 좋은 계절"
```

Claude는 `CLAUDE.md`의 규칙에 따라 4단계 파이프라인을 실행한다:

| 단계 | 산출물 | 내용 |
|---|---|---|
| 1 | `01_storyline.md` | 핵심 메시지 1개, 기승전결 (컷2의 질문 → 컷4의 대답) |
| 2 | `02_storyboard.md` | 6장 캐러셀 콘티 — **여기 대사가 이미지에 그려지는 글자다** |
| 3 | `03_render_prompts.md` | 컷별 이미지 생성 프롬프트 (나노바나나 + GPT) |
| 4 | `04_caption.md` | 인스타 게시글 캡션 — 툰의 요약이 아니라 **툰이 끝난 뒤 이어지는 사색** |

이후 `03_render_prompts.md`의 프롬프트를 이미지 생성 도구에 붙여넣어 컷을 렌더링하면 된다.

## 저장소 구조

```
brand/       브랜드 바이블 (정체성, 캐릭터, 그림체, 세계관, 성장 전략)
assets/      캐릭터 시트, 프로필, 기준 샘플 이미지
pipeline/    파이프라인 정의와 단계별 템플릿
episodes/    생성된 에피소드 (ep001은 형식·톤의 레퍼런스)
CLAUDE.md    파이프라인 오케스트레이션 규칙
```

## 핵심 원칙

- 한 화에는 하나의 메시지만
- 텍스트가 그림보다 많아지지 않는다
- 마지막 장은 항상 여운으로 끝낸다
